# 主歌词显示模型重构需求计划

## 背景

星河漫游 WebGL 歌词接管 DOM 歌词后，主歌词、上一句和下一句来自同一歌词窗口，但主歌词额外混入了歌曲标题、状态文字和空文本兜底逻辑，导致出现“上下句正常，中间主歌词显示歌名”的错误表现。主歌词需要从歌词解析、时间索引、WebGL 状态传递到贴图绘制形成单一职责链路。

## 目标

1. 主歌词只显示当前可唱/可展示歌词行，不在歌词 ready 后使用歌曲标题或文件名兜底。
2. 上一句、当前句、下一句必须从同一组过滤后的歌词行窗口生成，避免主句和侧句来源不一致。
3. 空态和错误态可以显示状态文字；加载态不进入 WebGL 中心主歌词，避免“在线歌词读取中”长期占据主句。
4. 过滤明显非歌词占位：纯音乐、间奏、完整文件名、艺人-标题式身份行；不过不过度过滤短句标题，避免误删真实歌词。
5. 保留当前句即时替换，不增加入场/退场动画、延迟层或 DOM 主歌词回退。
6. 不保存歌词文本、歌曲路径、播放 URL、Cookie、token、音频数据或本机运行历史。

## 非目标

1. 不重做在线歌词读取、音频识别或外部歌词服务。
2. 不改变歌词偏移、播放进度、音频分析和 WebGL 星河粒子运动逻辑。
3. 不把歌曲卡片、播放列表或右侧面板改成 3D 对象。
4. 不新增会导致歌词切换不同步的过渡动画。

## 实现步骤

1. 在 `useMusicLyrics.ts` 中把主歌词窗口改为“可显示歌词行 -> 当前显示索引 -> 三行窗口”的模型。
2. ready 状态下不再从 `track.title` 生成当前句；没有可显示歌词时返回空 ready 窗口，由上层决定是否隐藏。
3. 调整身份行过滤，只过滤文本本身像完整歌曲身份或文件名的行，避免把真实短句标题误删。
4. 在 `MusicWindow.vue` 中让 WebGL 当前句按 `textMode` 明确生成：歌词态显示歌词，空态/错误态显示状态，加载态保持中心为空，不再用歌曲标题或加载文案兜底。
5. 保留 `MusicWebglStarfield.vue` 的 WebGL CanvasTexture 绘制和行 key 缓存刷新机制。
6. 运行构建、`git diff --check`、隐私关键词扫描和 `.gitignore` 检查。

## 验收标准

- [x] 歌词 ready 后，主歌词不会显示歌曲标题、文件名或播放器标题。
- [x] 上一句、当前句、下一句来自同一组可显示歌词行。
- [x] WebGL 主歌词仍即时切换，不增加切换动画或 DOM 层歌词。
- [x] 空态和错误态仍有可读状态文字；加载态不占用中心主歌词。
- [x] 歌词读取请求有超时保护，不会长期保持 loading 并阻止重试。
- [x] 默认主题和 `animal-island` 主题不需要新增样式，继承现有 WebGL 歌词和状态样式。
- [x] 不新增歌词文本、歌曲路径、播放 URL、Cookie、token、音频数据或本机运行历史持久化。
