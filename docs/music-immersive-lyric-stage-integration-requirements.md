# 沉浸音乐歌词舞台融合需求计划

本文档记录参考 `XxHuberrr/Mineradio` 的歌词舞台、视觉控制台和歌词/舞台层级思路，对当前沉浸音乐模式歌词进行舞台化融合。本次只调整前端运行态显示、视觉偏好枚举和本机设置数值，不保存用户歌曲路径、播放 URL、歌词文本、平台 Cookie、token、音频数据或本机运行历史。

## 背景

- 当前沉浸歌词已经具备逐字进度、主题化光晕和上下句层级，但整体仍更像贴在舞台前方的字幕层。
- Mineradio 的可迁移原则是把歌词视为舞台对象：歌词位置、旋转、溢光和鼓点响应一起构成舞台层级。后续根据用户反馈，景深、镜头绑定和光粒调节已移除。
- 当前项目已有 WebGL 舞台、自由镜头、只看舞台和默认/`animal-island` 主题样式，适合在现有 DOM 歌词基础上做低风险融合。

## 目标

1. 只看舞台时仍保留歌词，隐藏控制区但不隐藏歌词舞台。
2. 歌词舞台固定为单一表现，不再提供清晰前景、舞台投影和沉浸漂浮三种预设。
3. 新增歌词舞台控制：
   - 倾角、溢光强度和歌词远近；鼓点溢光控制已取消。
   - 控制项保存为本机视觉偏好，不保存歌词文本或歌曲数据。
4. 歌词视觉和音乐能量协同：
   - bass/beat 驱动短促发光和轻微缩放。
   - 逐字进度继续驱动文字高亮和底部光轨。
   - 降低动态时禁用明显漂浮和强脉冲。
5. 地面 DJ 舞台下歌词移动到柱阵舞台中心上方，使用立体悬浮分层和下方投影；星河漫游继续保持原有悬浮歌词。
6. 默认主题和 `animal-island` 主题下均保持文字可读，动物岛主题使用更暖、更克制的光效。

## 非目标

- 不复制 Mineradio 的源码、shader、素材、Logo、命名或 GPL 实现。
- 不把歌词文本改为 WebGL 文字渲染；文字仍由 DOM 渲染以保证清晰度。
- 不改变网易云、酷狗、本地歌词读取和解析链路。
- 不新增完整取色器或复杂用户存档系统。
- 不保存用户歌曲路径、播放 URL、平台凭据、歌词文本或音频数据。

## 实施步骤

1. 梳理当前沉浸歌词 DOM、样式变量、只看舞台逻辑和本机设置保存逻辑。
2. 新增歌词舞台控制项、标准化函数和本机设置保存字段；后续移除歌词舞台预设及景深、光粒、镜头绑定调节。
3. 让只看舞台模式保留歌词，并根据播放列表/韵律面板隐藏状态调整歌词可用空间。
4. 扩展歌词舞台 CSS 变量，加入倾角、溢光和鼓点脉冲。
5. 在韵律面板新增“歌词舞台”控制分组。
6. 补齐默认主题和 `animal-island` 主题样式。
7. 更新完成/未完成功能记录。
8. 执行隐私检查、构建检查，并按桌宠重启规则运行 release 版。
