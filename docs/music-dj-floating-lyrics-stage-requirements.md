# 地面 DJ 歌词立体悬浮舞台需求计划

状态：已完成。

## 目标

让沉浸模式在使用“地面 DJ”舞台预设时，歌词成为柱阵舞台上方的立体悬浮对象，而不是贴在画面前方的普通字幕，也不是铺在地面上的扁平投影。

## 范围

- 仅调整沉浸模式下“地面 DJ”舞台的歌词视觉位置、透视和投影层级。
- “星河漫游”舞台继续使用原有悬浮歌词表现。
- 歌词仍使用 DOM 渲染，保证清晰度和现有逐字进度可继续工作。
- 本次不把歌词文本渲染进 WebGL 纹理，不做真实 WebGL 深度遮挡。
- 不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 实现规则

- 地面 DJ 下歌词整体下移到柱阵中心上方，让舞台和歌词处在同一视觉区域。
- 地面 DJ 下歌词保留正向 Z 轴距离，并让当前歌词、状态标签、光晕和下方投影分层，形成前后深度。
- 下方只保留椭圆反光和接触阴影，用来表达悬浮高度，不把主歌词压平成地面投影。
- 远近参数继续生效，同时改变 Z 轴距离和整体缩放。
- 保留字号、位置、远近、弱化、倾角、溢光和鼓点溢光控制。
- 默认主题和 `animal-island` 主题都要保持歌词可读。

## 验收

- [x] 地面 DJ 舞台下歌词显示在柱阵舞台中心上方，而不是画面中上部悬浮字幕。
- [x] 地面 DJ 舞台下当前歌词具有可见的前后层次和下方投影，不呈现贴地扁平效果。
- [x] 星河漫游舞台不受地面 DJ 悬浮参数影响。
- [x] 远近滑杆在地面 DJ 下仍能明显改变歌词大小和深度。
- [x] 默认主题和 `animal-island` 主题下歌词面板不溢出，歌词可读。
- [x] `npm run build` 通过。
- [x] `npm run tauri:build` 通过并启动 release 版。

## 记录

- 由于柱阵是 WebGL canvas，歌词是 DOM 层，本次实现为视觉悬浮和投影分层，不做柱体对歌词的真实遮挡。
- 改动只保存视觉参数，不保存用户本机音乐数据或平台凭据。
