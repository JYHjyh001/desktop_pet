# 沉浸音乐自由镜头与歌词可读性优化需求计划

本文档记录参考 `XxHuberrr/Mineradio` 自由镜头、鼠标转向、键盘移动、滚轮景深和歌词舞台呈现方式，对当前沉浸音乐模式进行交互与歌词视觉优化。本次只调整运行态界面交互、WebGL 相机状态和样式，不保存用户歌曲路径、播放 URL、歌词文本、平台 Cookie、token、音频数据或本机运行历史。

## 背景

- Mineradio 的自由镜头不是单纯拖动舞台，而是把鼠标、键盘、滚轮映射到相机位置、角度、侧滚和视野。
- 当前项目沉浸模式只支持鼠标拖动背景或歌词区域改变 `yaw/pitch`，角度范围较小，缺少前后左右、上下移动、侧滚和滚轮景深。
- 当前歌词主句周围存在一块偏矩形的大面积光效，歌词边缘在部分主题和深色背景上不够清楚。

## 目标

1. 新增沉浸模式自由镜头：
   - `R` 开关自由镜头。
   - 自由镜头开启后鼠标移动控制转向。
   - `W/A/S/D` 控制前后左右移动。
   - `Shift` 加速移动。
   - `Space/Ctrl` 控制升降。
   - `Q/E` 控制轻微侧滚。
   - 鼠标滚轮调整景深或视野。
   - `K` 平滑回正。
2. 保留现有舞台拖动：
   - 自由镜头未开启时，背景和歌词区域仍可使用原有拖动旋转。
   - 左侧播放列表、右侧韵律面板、底部控制栏和按钮继续稳定可点击。
3. 优化歌词边缘：
   - 当前歌词主句边缘更清晰，避免在高亮渐变中糊成一团。
   - 上下句仍保持弱化但可读。
   - 默认主题和 `animal-island` 主题下歌词边缘都要清楚。
4. 移除歌词附近大矩形光效：
   - 去掉当前主歌词后方大面积矩形/胶囊扫描光块。
   - 保留更轻量的文字阴影、边缘描边和非矩形氛围光。

## 非目标

- 不复制 Mineradio 源码、shader、素材或 GPL 实现。
- 不新增用户歌曲、歌词、播放 URL、平台凭据、路径或历史记录的持久化字段。
- 不改变音乐播放、歌词解析和平台播放链路。
- 不让自由镜头抢占输入框、按钮、滑块、列表滚动等 UI 控件。

## 实施步骤

1. 阅读项目规则、隐私清单和现有沉浸模式相机实现。
2. 参考 Mineradio 自由镜头的交互维度，设计当前项目可兼容的运行态自由镜头状态。
3. 在 `MusicWindow.vue` 中增加自由镜头状态、键盘/鼠标/滚轮输入和回正逻辑。
4. 在 `MusicWebglStarfield.vue` 中接收自由镜头状态，优先使用自由相机渲染；未开启时保留原相机轨道。
5. 在 `src/styles.css` 中去掉歌词矩形光效，增强歌词边缘清晰度，并补齐 `animal-island` 样式。
6. 执行构建、视觉检查和隐私检查。
