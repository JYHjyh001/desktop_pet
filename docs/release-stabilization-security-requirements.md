# 发布稳定化、安全收口与工程基线需求计划

状态：阶段 0、1、2 已完成；阶段 3、4 的发布基础项已完成，视觉回归与许可清单继续按清单推进。

## 背景

当前项目已经覆盖桌宠、快捷入口、AI 伴侣、翻译、本机记忆、音乐播放器、在线音乐、沉浸舞台和 Codex 状态聚合。继续增加功能前，需要先处理会影响发布安全、用户本机数据完整性、启动性能和后续可测试性的基础问题。

本计划优先于 AI 宠物素材转换和新的在线音乐能力。完成本计划后，再恢复体验类功能开发。

## 隐私与安全边界

- AI API Key、平台凭据、Bridge Token、歌曲路径、播放历史、快捷入口路径和本机导入资源只能作为用户本机数据处理。
- 敏感认证参数不得通过明文 HTTP 发送，不得进入 URL 查询参数、错误日志、诊断摘要或文档示例。
- 前端窗口只获取完成当前界面所需的最小配置；非设置窗口不得获取原始 API Key 或平台凭据。
- 本机文件读取必须由后端登记对象、受控目录或用户本次明确授权驱动，不能接受可组合成任意文件读取的前端路径。
- 数据目录迁移必须覆盖全部模块数据；冲突或校验失败时保留旧文件并提供可恢复信息。
- 本文档和测试数据只使用通用占位内容，不记录真实用户路径、账号、Cookie、token、歌曲或聊天内容。

### 划选翻译首次启用兼容方案

- 新安装生成的默认配置保留快捷键文本，但不注册划选翻译，直到用户在设置中保存并确认外部发送提示。
- 已有配置缺少同意字段时按“旧版本已启用”迁移，继续保持原快捷键行为，不擅自关闭用户现有功能。
- 用户清空快捷键后停止注册；以后再次启用时重新要求确认。
- 确认弹窗复用抽屉现有重要操作弹窗，默认主题和 `animal-island` 主题均继承已验证样式。
- 同意状态只保存布尔值，不保存选中文本、来源应用、窗口标题或翻译历史。

## 验收标准

1. 已知命令注入、任意文本读取和明文凭据传输路径不可再触发。
2. 切换自定义数据目录后，音乐库、配置、快捷入口、记忆、素材和平台登录状态保持一致；失败时旧数据不被删除。
3. 旧音乐库迁移后，聊天仍能取得不含歌曲路径的音乐摘要。
4. 异常退出前的最后一次收藏、标签、队列和设置修改不会因防抖计时器丢失。
5. 普通窗口无法读取原始 AI API Key 或平台 token。
6. 默认主题与 `animal-island` 主题的新增提示、错误、空状态和设置项均可读、无重叠。
7. 前端构建、严格类型检查、Rust 格式检查、Clippy、Rust 测试、依赖审计和隐私扫描通过。
