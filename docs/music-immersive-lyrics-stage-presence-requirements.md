# 沉浸模式歌词舞台感增强需求计划

## 背景

当前沉浸模式已经支持歌词舞台预设、景深、倾角、溢光、字号、位置、宽度、上下句弱化和进度高亮。用户希望歌词更像舞台的一部分，呈现悬浮在舞台中的空间感，并增强歌词和音乐之间的配合。参考对象为 Mineradio 的歌词舞台、粒子视觉和节奏电影镜头方向，但本项目只参考体验目标，不复制外部项目代码。

## 目标

- 让当前歌词在视觉上像悬浮在舞台中的前景层，而不是普通覆盖文字。
- 增加歌词下方的舞台投影、光带和空气感，让歌词与 WebGL 舞台背景更融合。
- 使用现有运行态音乐能量数据驱动歌词轻微抬升、漂浮、亮度和光粒强度。
- 保持歌词可读性优先，避免过强光效污染文字填充色或遮挡左右面板。
- 降低动态模式下禁用明显运动，只保留静态舞台层次。
- 默认主题和 `animal-island` 主题都需要继承或补充对应视觉样式。

## 范围

- 修改 `src/windows/MusicWindow.vue` 中沉浸歌词舞台 CSS 变量计算。
- 修改 `src/styles.css` 中沉浸歌词舞台、当前歌词、投影和光粒样式。
- 不改歌词解析、在线歌词获取、本地歌曲路径保存、播放 URL、Cookie、token 或音频数据持久化逻辑。
- 不新增需要保存的用户隐私数据，只复用现有本机视觉设置和运行态音乐能量。

## 实现步骤

1. 在歌词舞台样式计算中加入运行态音乐驱动变量，包括横向轻漂、纵向浮动、低频抬升、Z 轴距离、舞台光晕、空气光带和地面投影宽度。
2. 在歌词容器变换中加入轻微 Z 轴旋转，让歌词层和舞台镜头形成更自然的空间关系。
3. 给歌词堆栈增加舞台地面椭圆投影、扫描光带和当前歌词反射阴影。
4. 把当前歌词的 Z 轴抬升、光晕和进度线亮度与音乐能量联动。
5. 为降低动态、空状态、错误状态和未播放状态补充弱化规则。
6. 检查默认主题和 `animal-island` 主题下的文字可读性、投影强度和控件表现。

## 验收标准

- 播放时歌词有轻量悬浮、低频抬升和溢光响应，静止或暂停时不会突兀抖动。
- 当前歌词仍然清晰，文字内部不变脏、不灰黑，进度高亮可辨识。
- 舞台投影不遮挡底部控制栏、左右列表或韵律面板。
- 降低动态模式下不出现持续动画或明显漂浮运动。
- 默认主题和 `animal-island` 主题下视觉层次都正常。
- 构建通过，且不引入本机路径、歌曲数据、密钥或平台凭据到源码和文档。
