## 已确认需求

翻译窗口右上角提供设置入口，可选择共用全局 API 或独立翻译 API。窗口翻译与 Ctrl+Alt+T 划选翻译使用同一配置和专用翻译提示词，不继承聊天人格、记忆或故事上下文。

旧配置默认共用全局。独立模式不依赖全局 AI 开关，不自动复制全局密钥，失败不回退到其他服务；模式切换保留独立连接设置。保存只更新翻译配置，抽屉保存不能覆盖翻译设置。请求使用开始时的配置快照。

独立接口沿用现有 OpenAI 兼容、DeepSeek、Anthropic、Gemini、Ollama、自定义 OpenAI 兼容适配及传输校验。密钥仅存本机；读取只返回 hasApiKey，普通保存保留密钥，支持明确替换或清除。测试使用当前草稿且不保存。

## 实现摘要

- `src-tauri/src/translation_api.rs`：生效连接解析、安全摘要、草稿密钥语义与传输校验。窗口与划选在命令入口读取配置快照，使用专用翻译提示词。
