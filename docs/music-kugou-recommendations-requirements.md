# 酷狗推荐歌单扩展需求计划

## 目标

在现有酷狗搜索、登录和个人歌单能力基础上，增加酷狗只读推荐内容浏览，让用户可以在音乐窗口里获取推荐歌单、每日推荐歌曲，并复用现有歌词、临时在线播放和沉浸模式播放列表能力。

## 本轮范围

1. 参考 MakcRe/KuGouMusicApi 的 `/top/playlist`、`/playlist/detail`、`/playlist/track/all`、`/everyday/recommend` 和 `/everyday_song_recommend` 接口形态，后端新增酷狗推荐内容只读命令。
2. 推荐歌单列表支持未登录读取，返回歌单 ID、名称、封面、歌曲数、作者、更新时间等摘要。
3. 推荐歌单详情优先通过公开歌单歌曲接口读取，返回歌曲 hash、歌名、歌手、专辑、封面、时长和费用标记等摘要。
4. 每日推荐歌曲在有酷狗登录态时优先带本机登录凭据请求；未登录或接口不可用时显示明确提示，不写入本地音乐库。
5. 前端酷狗页签左侧增加“推荐歌单”分组，与“我的歌单”共用卡片式列表；右侧内容区展示推荐歌单详情或每日推荐歌曲。
6. 搜索结果、个人歌单、推荐歌单和每日推荐歌曲都复用当前酷狗歌词、运行态播放、不可播放标记和沉浸模式播放列表。
7. 音乐窗口大小可适当扩展，保证推荐分组、歌单列表、歌曲详情和错误提示不挤压。
8. 默认主题和 `animal-island` 主题都需要检查；新增列表、按钮、空状态、错误提示和分组标题应继承或补齐样式。

## 非本轮范围

1. 酷狗收藏、创建歌单、删除歌单、增删歌曲等写操作。
2. 绕过会员、版权、地区、DRM、设备风控或付费限制。
3. 上传歌曲文件、歌曲路径、音频指纹、播放历史或账号凭据到外部识别服务。
4. 把酷狗推荐结果、播放 URL、Cookie、token、设备标识或用户本机路径写入源码、文档示例或仓库。
5. 将推荐歌单持久化成本地曲库；本轮只作为运行态在线内容展示。

## 隐私与合规边界

1. 酷狗账号凭据继续只保存在本机应用数据目录 `music-platforms` 下。
2. 推荐歌单、每日推荐和歌曲详情只作为前端运行态状态保存，不写入 `localStorage`、源码或项目文档示例。
3. 播放 URL 只在当前运行态播放链路中使用，不返回给用户展示，不写入本地音乐库。
4. 错误提示只展示脱敏原因和建议，不展示 token、Cookie、设备标识或完整上游播放链接。

## 验收标准

1. 酷狗页签左侧出现“推荐歌单”分组，可刷新并展示推荐歌单摘要。
2. 未登录状态下可以读取公开推荐歌单；个人歌单和每日推荐需要登录时显示清晰状态。
3. 点击推荐歌单后，右侧显示歌曲摘要列表，并可继续加载后续页。
4. 每日推荐歌曲能作为独立在线列表展示，歌曲行可读取歌词和尝试临时播放。
5. 沉浸模式酷狗播放列表优先展示当前酷狗详情列表：推荐歌单、每日推荐、个人歌单或搜索结果。
6. 默认主题与 `animal-island` 主题下，新增分组、卡片、列表、按钮、空状态和错误提示不发生明显遮挡或文本溢出。
7. `npm run build` 通过，隐私关键词扫描没有真实密钥或本机私密数据。
