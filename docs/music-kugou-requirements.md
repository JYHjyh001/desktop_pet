# 酷狗音乐接入需求计划

## 目标

参考现有网易云音乐接入方式，为音乐窗口增加酷狗音乐在线平台能力，让用户可以在本机应用内搜索酷狗歌曲、查看在线歌词、尝试临时在线播放，并在沉浸模式播放列表中切换到酷狗结果。

## 本轮范围

1. 新增酷狗平台入口，与网易云共用音乐平台面板样式。
2. 支持关键词搜索酷狗歌曲，搜索结果作为临时在线播放列表展示。
3. 支持读取酷狗歌词，优先使用 LRC 歌词，沉浸模式可同步显示。
4. 支持从酷狗搜索结果临时在线播放可用歌曲；版权、会员、地区或接口限制导致播放地址为空时显示明确错误。
5. 沉浸模式左侧播放列表支持切换到酷狗搜索结果。
6. 默认主题和 `animal-island` 主题都继承或补齐对应界面样式。

## 第二轮范围：登录能力

1. 参考网易云二维码登录方式，新增酷狗二维码登录入口。
2. 后端生成酷狗登录二维码 key 和二维码图片，前端只展示二维码、过期时间和扫码状态。
3. 后端轮询酷狗扫码状态，授权成功后仅保存必要的本机登录凭据和脱敏账号摘要。
4. 前端展示酷狗登录状态、昵称、用户 ID 和本机保存时间，不展示 token、Cookie、设备 ID 等凭据字段。
5. 支持刷新酷狗登录状态和清除本机酷狗登录状态。
6. 酷狗搜索、歌词和临时播放继续可在未登录时使用；登录状态仅作为后续个人歌单和更完整播放能力的基础。

## 非本轮范围

1. 酷狗收藏管理、新建歌单、删除歌单、增删歌单歌曲等写操作。
2. 酷狗会员资源解锁、版权绕过、地区限制绕过或客户端下载兜底。
3. 上传音频、音频指纹、歌曲路径或本机资源到外部识别服务。
4. 将酷狗搜索结果、播放地址、账号凭据或用户本机音乐路径写入源码或仓库。

## 隐私与合规边界

1. 酷狗搜索结果和歌词只作为运行时临时状态使用。
2. 酷狗登录凭据只能保存到本机应用数据目录的 `music-platforms` 子目录，不写入 `config.json`、`localStorage`、源码或文档示例。
3. 临时播放地址只保存在当前播放状态中，不写入本地音乐库或文档示例。
4. 播放失败时只展示原因，不绕过版权、会员或地区限制。

## 验收标准

1. 音乐窗口顶部平台切换中出现“酷狗”。
2. 输入关键词后可以获取酷狗搜索结果。
3. 搜索结果行展示歌曲名、歌手、专辑、时长，并提供“歌词”和“播放”操作。
4. 在线歌词可在酷狗面板预览，并可被沉浸模式自动读取。
5. 点击可播放歌曲后，当前播放状态显示酷狗来源；如果播放地址不可用，显示清晰错误且不影响本地/网易云播放。
6. 沉浸模式左侧播放列表可切换“酷狗”，展示当前酷狗搜索结果并可点击播放。
7. `npm run build` 通过。

## 第二轮验收标准

- [x] 酷狗页签展示登录状态、刷新、扫码登录和退出按钮。
- [x] 点击扫码登录后生成二维码，并可轮询展示等待扫码、已扫码、已授权、过期或失败状态。
- [x] 授权成功后前端只显示账号摘要，不显示 token、Cookie 或设备标识。
- [x] 清除登录会删除本机酷狗凭据并重置前端状态。
- [x] 未登录时酷狗搜索、歌词和临时播放仍可继续尝试。

## 第三轮范围：个人歌单

- [x] 后端提供读取当前酷狗账号个人歌单列表命令。
- [x] 后端提供读取单个酷狗歌单歌曲摘要命令。
- [x] 歌单列表只返回歌单 ID、名称、封面、歌曲数、创建者、更新时间等摘要字段。
- [x] 歌单详情只返回歌曲 hash、歌曲名、歌手、专辑、封面、时长和费用标记等摘要字段，不返回播放地址。
- [x] 前端酷狗页签支持登录后读取个人歌单、切换歌单并展示歌曲摘要。
- [x] 酷狗个人歌单歌曲行复用“歌词”和“播放”操作，播放仍只创建当前运行态临时曲目。
- [x] 沉浸模式酷狗播放列表优先展示当前酷狗个人歌单；没有歌单详情时回退酷狗搜索结果。
- [x] 默认主题和 `animal-island` 主题沿用现有平台歌单、歌曲摘要、空状态和错误提示样式。
