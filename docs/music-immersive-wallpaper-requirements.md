# 沉浸模式导入壁纸需求计划

本文档记录沉浸模式新增本机壁纸导入能力的实现计划。本功能只保存用户选择的本机图片或视频路径、媒体类型和视觉参数到本机运行态设置，不复制图片或视频到仓库，不上传媒体内容，不把用户本机路径、图片内容、视频内容、歌曲路径、播放 URL、平台 Cookie、token、音频数据或运行历史写入源码、文档示例或提交内容。

## 背景

当前沉浸模式主要依赖主题背景、Canvas/WebGL 可视化和歌词舞台形成氛围。用户希望参考 Mineradio 的沉浸视觉方向，允许导入本机图片或视频壁纸作为舞台背景，并保持音乐播放与可视化流畅。

## 目标

1. 在沉浸模式韵律面板中新增壁纸控制区，可选择本机图片或本机视频作为沉浸背景。
2. 壁纸位于舞台背景层，不遮挡歌词、搜索、播放列表、韵律面板和底部控制栏。
3. 支持显示/隐藏壁纸、移除壁纸，并提供强度和柔化调节。
4. 图片使用静态 CSS 背景图和 GPU 合成层；视频使用原生 video 背景层、静音循环和浏览器解码，不进入逐帧 Canvas/WebGL 渲染循环。
5. 默认主题和 `animal-island` 主题下保持文字可读、控件不拥挤、背景不抢歌词焦点。
6. 视频壁纸优化不得压缩、转码、降分辨率或降低码率；掉帧时只降低其他可视化负载或关闭昂贵滤镜，保持用户原视频画质。

## 非目标

1. 不提供在线壁纸搜索、壁纸下载或外部服务接入。
2. 不复制、压缩、缓存或提交用户壁纸图片、视频。
3. 不把壁纸路径写入文档示例、源码常量或仓库。
4. 不改变网易云、酷狗等平台搜索和播放授权边界。
5. 不在降低动态模式下增加额外动画。
6. 不自动生成压缩版视频、不改写用户视频文件、不缓存转码结果。

- [x] 显示/隐藏、移除、强度和柔化调节即时生效。

- [x] 视频壁纸静音循环播放，隐藏或移除后停止显示，不遮挡歌词和控件。
- [x] 视频壁纸不进入 Canvas/WebGL 逐帧处理链路，不保存视频内容、播放历史或平台凭据。
- [x] 默认主题和 `animal-island` 主题下视频壁纸控制区、预览区和错误提示可读。
- [x] 构建和浏览器验证通过，隐私检查确认没有新增真实密钥、用户本机路径或视频文件。
- [x] 视频壁纸开启后不再对动态视频层应用全屏 blur/filter。
- [x] 掉帧监控只保存在运行态，不写入本机设置、源码或文档示例。
- [x] 掉帧保护触发时视频仍使用原始文件、原始分辨率和原始码率。
- [x] 视频壁纸作为沉浸场景稳定背景层播放，不随音乐驱动的舞台 `translate/rotate/scale` 变化。
- [x] 视频壁纸开启时，Canvas 背景不再逐帧绘制；WebGL 和歌词继续在上层工作。

## 验证记录

- `npm run build` 通过，只有 Vite 现有的 chunk 体积提示。
- 默认主题浏览器验证通过：导入后壁纸层位于 Canvas 背景之上、WebGL 和歌词层之下；隐藏会移除壁纸层，显示可恢复，移除后按钮禁用。
- `animal-island` 主题浏览器验证通过：壁纸卡片、预览区、按钮和壁纸滤镜命中主题样式，隐藏、显示和移除状态同步。
- 隐私边界检查通过：新增逻辑不提交壁纸文件，不在源码或文档中记录真实本机路径，不保存播放 URL、平台 Cookie、token、音频数据或运行历史。
- 视频壁纸浏览器验证通过：默认主题和 `animal-island` 主题下，视频背景层静音循环播放，隐藏和移除会移除 video 节点，卡片、按钮和滤镜样式保持主题适配。
- 视频壁纸原画优化验证通过：默认主题和 `animal-island` 主题下，视频壁纸父层与 video 元素计算样式均为 `filter: none`；柔化仅调整遮罩变量，视频源仍按原始文件播放；掉帧监控只在运行态降低 Canvas/WebGL 有效强度。
- 视频壁纸结构优化验证通过：视频节点位于沉浸场景稳定背景层，不再作为 3D 舞台子节点；视频启用时舞台内 Canvas 背景不渲染，降低音乐播放后的视频重合成压力。
