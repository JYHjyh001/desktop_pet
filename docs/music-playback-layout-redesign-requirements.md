# 音乐播放布局重设计需求

本文档记录音乐播放窗口布局重设计的目标、范围和验收要求。用户本机歌曲路径、平台凭据、播放历史、播放 URL 和导入资源不得写入本文档。

## 背景

当前音乐窗口已集成本地音乐、网易云、酷狗、沉浸模式、歌词、歌单、搜索和设置等能力。功能集中后，普通播放器首页的当前播放区、控制区、状态提示和内容列表上下堆叠，视觉层级偏拥挤，用户在播放、切换来源和管理列表时需要频繁扫视。

## 设计目标

- 将普通音乐窗口调整为更清晰的工作台布局，减少当前播放与列表内容互相挤压。
- 让“正在播放、核心控制、来源切换、列表内容、状态提示”形成稳定层级。
- 保留现有交互和数据边界，不改变本地音乐、网易云、酷狗和沉浸模式的业务行为。
- 默认主题与 `animal-island` 主题都要有对应样式，不能只适配单一主题。

## 本轮范围

- 重排普通音乐窗口，不重做沉浸模式全屏布局。
- 将当前播放信息和核心控制整合为更宽松的顶部播放面板。
- 将播放进度、音量、随机和循环等次级控制组织到独立区域。
- 将本地/网易云/酷狗内容区放入更明确的内容工作区。
- 保持迷你播放器、设置弹窗、歌曲编辑弹窗、歌词弹层和平台登录逻辑可用。

## 不在本轮范围

- 不新增真实封面抓取或外部识别服务。
- 不上传本机音频、路径、指纹或平台凭据。
- 不新增音乐平台账号能力。
- 不重新设计沉浸模式的视觉系统。

## 布局要求

- 桌面宽度下使用双列或分区式布局：左侧/顶部强调当前播放和控制，右侧/主体承载列表与平台内容。
- 中等宽度下保持内容可阅读，控制按钮不挤压标题和进度。
- 窄宽度下自动回退为单列，按钮和进度条不溢出。
- 当前歌曲标题、歌手、来源和时长必须有清晰主次层级。
- 状态提示和错误提示需要靠近播放区，但不能打断列表浏览。

## 主题要求

- 默认主题：保持现有轻量、半透明、柔和边框风格。
- `animal-island` 主题：继承纸感卡片、暖色边框和岛屿主题控件风格。
- 新增容器、按钮、输入框、列表、空状态、错误提示必须确认可继承或补齐主题样式。

## 验收标准

- `npm run build` 通过。
- 普通音乐窗口在默认主题下不再呈现当前播放、控制和列表上下拥挤。
- `animal-island` 主题下新增布局容器和按钮视觉一致。
- 本地音乐、网易云、酷狗页签仍可切换。
- 播放、暂停、上一首、下一首、进度拖动、音量调整仍保持可用。
- 不新增或提交本机隐私数据、平台凭据、播放 URL 或构建产物。
