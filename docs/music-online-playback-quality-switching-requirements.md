# 在线播放音质即时切换需求

本文档记录参考 Mineradio 的播放中音质切换方式，对当前在线音乐播放进行即时切换增强。本次只调整运行态播放链路刷新和界面状态，不保存播放 URL、Cookie、token、设备标识、用户歌曲路径或本机资源。

## 背景

- 当前在线播放音质偏好可以保存，并会影响后续网易云、酷狗播放地址请求。
- 用户在播放过程中切换音质时，希望当前歌曲立即重新获取对应音质播放地址，而不是等到下一首。
- Mineradio 的做法是切换音质后记录当前播放进度，重新请求目标音质 URL，替换音频源，再跳回原进度继续播放。

## 目标

1. 在线音乐播放中切换“在线播放音质”时，立即刷新当前网易云或酷狗播放链路。
2. 切换时记录当前播放进度，新音源加载后从原进度继续播放。
3. 切换过程中禁用音质按钮，避免重复请求。
4. 如果当前不是正在播放的在线歌曲，只保存音质偏好，并提示下次播放生效。
5. 切换失败时恢复上一档音质偏好和原播放链路，并展示可理解错误，避免当前歌曲停在失败的新链路上。
6. 普通设置面板和沉浸模式底部播放控制栏都提供音质切换入口，并复用同一套运行态切换逻辑。
7. 沉浸模式音质切换使用列表弹层展示，列表项包含档位名称和规格说明，避免多个横向按钮挤占底部控制栏空间。
8. 音质列表按当前平台动态切换，网易云和酷狗分别展示自己的档位，并分别保存各自的偏好。
9. 酷狗切换到高品、无损、Hi-Res 或蝰蛇类音质时，如果接口实际返回标准音质，本次切换按失败处理并恢复上一档。
10. 音质缓存和正在请求的播放源按“歌曲 + 音质”隔离；切换失败恢复时直接恢复旧播放源和旧进度，不再重新请求旧音质，避免无法继续播放。
11. 新音质播放源获取成功后，按歌曲身份判断当前播放目标，避免 Vue 响应式对象引用变化导致静默返回；新音源开始播放后立即结束“正在切换”状态。

## 边界

- 不提前获取并保存所有音质播放源。
- 不读取或复用官方客户端缓存。
- 不绕过会员、版权、地区、DRM、设备风控或付费限制。
- 不把真实播放 URL、登录凭据、设备标识、本机歌曲路径或用户账号隐私写入源码、文档或曲库。
