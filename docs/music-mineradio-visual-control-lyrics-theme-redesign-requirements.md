# Mineradio 视觉控制参考下的主题与歌词呈现重设计需求计划

本文档记录参考 `XxHuberrr/Mineradio` 的视觉控制台、歌词舞台和主题色控制方式，对当前沉浸音乐模式进行主题与歌词呈现样式重设计。本次只调整前端结构、主题变量和视觉样式，不保存用户歌曲路径、播放 URL、歌词文本、平台 Cookie、token、音频数据或本机运行历史。

## 背景

- Mineradio 的核心视觉思路是把播放界面作为舞台：视觉控制台提供预设、颜色、歌词外观、叠加效果和 3D 相关分组，歌词与粒子、光晕和镜头层级协同。
- 当前项目沉浸模式已经有多主题、WebGL/Canvas 可视化和歌词同步，但主题入口仍偏普通按钮网格，歌词状态、当前行进度和主题色之间的关系还不够像“舞台控制”。
- 项目要求新增或调整前端功能时，同时检查默认主题和 `animal-island` 主题表现。

## 目标

1. 重设计沉浸韵律面板的主题呈现：
   - 主题不再只是短按钮，改为带色板、标题和说明的视觉预设卡。
   - 主题卡要表达背景、强调色、歌词色和光晕色之间的关系。
   - 当前主题状态清晰，保存中和错误提示不挤压其它控制。
2. 强化歌词呈现样式：
   - 当前歌词保留唱词进度高亮，并增加更明确的舞台扫描线、柔光边界和主题化色彩。
   - 上下句保持可读但退到后景，减少与主句竞争。
   - 空状态、错误状态和未播放状态要弱化，不遮挡舞台主视觉。
3. 参考 Mineradio 视觉控制台的信息结构：
   - 视觉模式、频谱、线条、波纹、主题和歌词校准分组层级更清楚。
   - 主题和歌词相关控件使用稳定尺寸，避免切换时布局跳动。
4. 默认主题、`animal-island` 主题和独立沉浸主题都要有对应样式或确认继承稳定。

## 非目标

- 不复制 Mineradio 的源码、shader、素材或 GPL 实现。
- 不新增歌曲、歌词、播放 URL 或平台凭据的持久化字段。
- 不改变网易云、酷狗、本地音乐的播放链路和歌词解析逻辑。
- 不新增完整自定义歌词颜色取色器；本次只重设计现有主题和歌词显示。

## 实施步骤

1. 阅读当前项目隐私清单、音乐需求和现有沉浸模式实现。
2. 查看 Mineradio 的 README、视觉控制台、歌词舞台和桌面歌词视觉边界，提炼可迁移的设计原则。
3. 在 `MusicWindow.vue` 中为沉浸主题选项补充色板数据，并调整主题选择模板。
4. 在 `src/styles.css` 中增加主题卡、歌词舞台扫描线、歌词状态和 `animal-island` 覆盖样式。
5. 更新完成/未完成功能记录。
6. 执行构建验证和隐私检查。
