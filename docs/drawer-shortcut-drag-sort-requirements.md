# 抽屉快捷卡片拖拽排序需求

## 目标

用户可在抽屉中直接拖动快捷卡片，将卡片放到当前列表中的任意位置，并在重启应用后保留排列结果。

## 功能范围

- 紧凑和详细两种卡片显示方式均支持拖拽排序。
- 拖动过程中显示正在拖动和可放置目标的视觉反馈。
- 松手后立即更新界面，并将完整排序保存到本机 `apps.json`。
- 在搜索、类型筛选或分类中排序时，只调整当前可见卡片，不打乱被隐藏卡片的相对顺序。
- 保存失败时恢复原顺序，并在抽屉中告知用户。
- Windows 抽屉 WebView 关闭 Tauri 原生文件拖放拦截，保证卡片的 HTML5 `dragover` / `drop` 事件可用。

## 数据与隐私边界

- 排序仅保存快捷入口的本机 ID 顺序，不增加任何上传、外部服务或遥测。
- 后端必须验证提交的 ID 集合与当前本机快捷入口完全一致，拒绝缺失、重复或未知 ID。

## 主题与验收

- 默认主题和 `animal-island` 主题均需要有清晰的拖动态、目标态和状态提示。
- 前端测试覆盖排序成功、筛选列表排序和保存失败回滚。
- Rust 测试覆盖合法排序以及缺失、重复、未知 ID 拒绝。
