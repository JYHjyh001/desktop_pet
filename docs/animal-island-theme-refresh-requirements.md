本文档记录 `animal-island` 主题对齐 `animal-island-ui` 最新 main 的增强计划。不得记录用户本机路径、配置、密钥、音乐文件、导入资源或运行历史。

当前项目已有 `animal-island` 主题，但样式主要集中在 `src/styles.css` 中，存在少量变量别名缺失和多轮追加后的覆盖分散问题。本次先做低风险主题增强，不引入 React 组件库，不改变用户数据存储逻辑。

## 功能目标

1. 修复 `animal-island` 主题变量缺失，避免断开状态气泡和聊天表情按钮出现颜色回退异常。
2. 补充主题 token，使颜色、圆角、阴影、动效、纸感背景可复用。
3. 增强按钮、输入框、切换控件、标签页、卡片、空状态、弹窗、聊天气泡、音乐窗口和宠物状态气泡的动物岛视觉一致性。
4. 保持默认主题不受影响，所有新增选择器只作用于 `.theme-animal-island` 或对应动物岛窗口类。
5. 不写入用户本机数据，不记录真实路径、歌曲、AI 配置或 API Key。

## 本次实现范围

- CSS 变量别名和上游风格 token。
- 动物岛主题字体栈优先级调整，优先使用 `Nunito` / `Noto Sans SC`，无本地字体时回退系统中文字体。
- 胶囊按钮和输入框的焦点、悬浮、按压状态增强。
- 卡片、设置面板、音乐面板、剧情面板和空状态增加低透明纸感点纹。
- 小型弹窗和独立宠物气泡强化纸感边框、阴影和气泡尾巴。
- 加载中按钮增加轻量薄荷斜纹动效。

## 非目标

- 不引入 `animal-island-ui` React 组件。
- 不复制上游大量图片、字体文件或演示资产。
- 不调整音乐本机数据、歌曲路径、分类、播放列表和存储目录。
- 不改动 AI API Key、Base URL、聊天配置和本机运行时数据。
- 不打包、不提交、不发布 release，除非用户另行要求。

3. 新增窗口、弹窗、按钮、输入框、列表、空状态、错误提示必须具备动物岛主题样式或确认继承现有样式。
