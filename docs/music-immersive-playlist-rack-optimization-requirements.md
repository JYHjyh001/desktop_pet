# 沉浸模式“我的歌单”歌单架优化需求计划

状态：已完成，并通过双主题预览、前端测试、类型检查、隐私门禁和完整 Tauri Release 构建验证。

## 背景

- 当前沉浸模式已经把左侧列表拆成“当前列表 / 我的歌单”，并支持本地、网易云和酷狗歌单。
- “我的歌单”当前按平台纵向堆叠完整区块；歌单数量较多时浏览路径长，展开详情后容易把其它平台入口推离视区。
- 本地歌单与在线歌单的展开状态和播放后停留行为不一致，本地歌单点击“播放”后会切回“当前列表”，不利于继续在原歌单中选歌。
- 本次参考 `XxHuberrr/Mineradio` 的统一歌单面板、紧凑歌单卡、单一内联详情、详情播放入口和渐进呈现思路，但不复制其 GPL 源码、Shader、素材、Logo、命名或原创视觉表达。

## 隐私与数据边界

- 歌曲路径、歌单内容、平台登录态、播放历史、封面来源和歌曲文件目录继续只保存在用户本机运行时数据中。
- 不新增外部音乐识别、音频上传、音频指纹或第三方分析服务。
- 不把真实歌曲、歌单、账号、Cookie、token、本机路径或播放 URL 写入源码、测试夹具、需求文档或仓库。
- 在线封面和歌曲摘要继续复用现有平台接口与运行态数据，不新增持久化字段。

## 目标

1. 将“我的歌单”改造成统一歌单架：
   - 增加“全部 / 本地 / 网易云 / 酷狗”来源筛选。
   - 来源按钮显示歌单数量，快速判断各来源是否已有内容。
   - “全部”模式仍按来源分组，但只展示紧凑歌单卡，不再为每个平台保留厚重的嵌套面板。
2. 统一歌单卡和详情层级：
   - 歌单卡展示封面或来源占位、名称、歌曲数/摘要和来源标记。
   - 同一时间最多展开一个歌单详情，避免多个详情同时撑高面板。
   - 详情头部展示歌单信息、播放歌单、加入队列或加载更多等可用操作。
   - 歌曲行展示封面占位、歌名、歌手、时长/可播放状态，并突出当前播放歌曲。
3. 优化连续选歌体验：
   - 从“我的歌单”播放本地歌单或其中歌曲后继续停留在“我的歌单”。
   - 在线歌单继续保留现有临时播放、不可播放提示和分页加载链路。
   - 切换来源筛选不会清空已加载的本机歌单数据或平台歌单摘要。
4. 兼顾面板性能和可访问性：
   - 不一次性创建新的全量数据副本，继续复用现有 Map/Set 和平台分页结果。
   - 筛选按钮使用 tab 语义；展开按钮同步 `aria-expanded`，当前歌曲保留 `aria-current`。
   - 加载、未登录、空歌单、不可播放和错误状态都提供可读文案。
5. 默认主题和 `animal-island` 主题都要完成样式检查。

## 非目标

- 不实现 Mineradio 的 3D 歌单架、镜头跟随、滚轮选择音效或手势控制。
- 不恢复普通音乐主界面已经下线的旧自定义歌单页面结构。
- 不新增歌单封面编辑、在线歌单增删改、跨平台合并写入或云端同步。
- 不改变网易云、酷狗的版权、会员、地区、DRM 和试听限制处理。

## 实施步骤

1. 新增沉浸歌单来源筛选和独立的本地歌单展开状态。
2. 统一本地、网易云、酷狗歌单的单一展开规则和播放后停留规则。
3. 重构沉浸“我的歌单”模板为来源筛选、分组歌单卡和内联详情三层结构。
4. 增加默认主题和 `animal-island` 主题的歌单架、筛选按钮、卡片、详情头、歌曲行、空状态与错误状态样式。
5. 补充前端回归测试，覆盖来源筛选、单一展开和本地歌单播放后停留。
6. 更新完成/未完成功能记录，执行类型检查、前端测试、完整 Tauri 构建和隐私检查。

## 2026-07-13 歌单播放位置保持修正

### 问题澄清

- “保持在当前位置”同时包含歌单架滚动位置和歌曲播放位置；此前只处理了歌单架滚动位置。
- 本地、网易云和酷狗的“播放歌单”逻辑都固定选择歌单第一首，当前歌曲已经属于该歌单时仍会重新从第一首和 0 秒开始。

### 验收结果

- [x] 当前歌曲属于所选歌单时，“播放歌单”只更新后续播放上下文，不更换歌曲、不归零播放时间。
- [x] 当前歌曲处于暂停状态时从原时间继续；正在播放时不重复调用媒体播放或重新获取在线地址。
- [x] 当前歌曲不属于所选歌单时，仍从第一首开始播放，保留按钮原有语义。
- [x] 本地、网易云和酷狗三类歌单使用一致规则。
- [x] 双主题酷狗沉浸测试覆盖第二首播放到 42 秒后再次点击“播放歌单”，验证歌曲、时间、展开歌单和歌词请求次数均保持正确。

## 2026-07-13 详情读取与加载更多位置保持

### 问题

- 之前只有网易云、酷狗的整个平台“刷新”操作保存了歌单架 `scrollTop`。
- 点击在线歌单读取详情、以及在详情中“加载更多”没有经过滚动保护；详情清空和重新插入期间列表高度变化，会把滚动位置压回顶部。
- 酷狗详情读取完成后还会临时切换到“当前列表”，导致“我的歌单”滚动容器被卸载并重新创建。

### 验收结果

- [x] 网易云和酷狗点击歌单读取详情后恢复读取前的歌单架滚动位置。
- [x] 网易云和酷狗详情“加载更多”完成后恢复加载前的滚动位置。
- [x] 酷狗详情读取期间保持“我的歌单”来源，不再卸载滚动容器。
- [x] DOM 更新后立即恢复一次，并在下一渲染帧再次校正，覆盖异步列表高度稳定过程。
- [x] 默认主题和 `animal-island` 自动化测试均模拟详情读取把滚动位置重置为 0，并验证最终恢复到原位置。
