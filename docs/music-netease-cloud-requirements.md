# 网易云音乐接入需求计划

本文档记录宠物电台接入网易云音乐的阶段计划。账号凭据、Cookie、用户信息缓存和平台歌单缓存都属于用户本机数据，只能保存到运行时应用数据目录，不能写入源码、文档示例或仓库。

## 目标

- 在音乐窗口中加入网易云音乐账号入口。
- 先通过网易云 App 扫码完成账号授权。
- 登录状态、昵称和头像只用于本机界面展示。
- Cookie 只保存在本机应用数据目录的独立平台凭据文件中，不返回给前端展示。
- 后续再基于登录状态逐步实现歌曲搜索和更完整的合规播放跳转。

## 第一阶段范围

- [x] 后端提供创建二维码登录、检查二维码状态、读取登录状态和清除登录状态命令。
- [x] 前端音乐窗口新增“网易云”页签。
- [x] 前端支持生成二维码、自动轮询扫码状态、展示登录成功/等待扫码/已过期等状态。
- [x] 登录成功后仅展示昵称、用户 ID 和头像，不展示 Cookie。
- [x] 退出登录只清除本机保存的网易云凭据。
- [x] 默认主题和 `animal-island` 主题补齐网易云面板样式。

## 第一阶段不做

- [ ] 不下载或缓存网易云音频文件。
- [ ] 不绕过版权、会员、地区或 DRM 限制。
- [ ] 不上传本地音乐、音频指纹、歌曲路径或用户本机播放历史。
- [ ] 不把网易云 Cookie 写入 `config.json`、`localStorage`、源码或文档示例。
- [ ] 不直接复刻第三方项目的 Electron Cookie 提取方案。

## 第二阶段范围

- [x] 后端提供读取当前登录账号歌单列表命令。
- [x] 后端提供读取单个歌单歌曲摘要命令。
- [x] 歌单列表只返回歌单 ID、名称、封面、歌曲数、播放数、收藏数、创建者昵称等摘要字段。
- [x] 歌单详情只返回歌曲 ID、歌曲名、歌手、专辑、封面、时长和费用标记等摘要字段，不返回播放地址。
- [x] 前端“网易云”页签支持读取歌单、切换歌单并展示歌曲摘要。
- [x] 默认主题和 `animal-island` 主题补齐歌单列表、歌曲摘要列表、空状态和错误提示样式。

## 第三阶段范围

- [x] 后端提供读取单首网易云歌曲在线歌词命令。
- [x] 后端提供获取单首网易云歌曲临时播放 URL 命令。
- [x] 在线歌词只返回歌词文本、翻译歌词、来源和提示信息，不返回 Cookie。
- [x] 在线播放只使用接口返回的可访问 HTTP(S) 音频 URL；如果返回空 URL、无版权、会员限制或地区限制，则显示不可播放原因。
- [x] 前端歌单歌曲行新增“歌词”和“播放”操作。
- [x] 在线播放歌曲只作为当前运行态临时曲目，不写入本地音乐库、歌单、`localStorage` 或源码文档。
- [x] 默认主题和 `animal-island` 主题补齐在线歌词、在线播放按钮和当前播放状态样式。

## 第四阶段范围

- [x] 后端读取网易云歌词时分离返回 `lrcContent`、`yrcContent`、`klyricContent` 和翻译歌词，Cookie 不返回前端。
- [x] 前端网易云歌词优先解析 YRC 逐字时间戳，解析失败时自动回退普通 LRC。
- [x] 沉浸模式当前歌词进度优先使用 YRC 片段时间推进；没有 YRC 时继续使用普通行级同步和长间奏估算。
- [x] 网易云歌词预览区显示当前歌曲是否返回逐字歌词，默认不展示原始 YRC 格式文本。
- [x] 默认主题和 `animal-island` 主题沿用现有沉浸歌词样式，不新增账号、Cookie、播放链接或歌曲路径持久化。

## 后续阶段

1. 搜索与跳转：支持搜索网易云歌曲，并打开网易云官方页面或客户端处理播放。
2. 播放策略增强：提供官方客户端或网页跳转作为在线播放失败时的兜底入口。
3. AI 联动：AI 推荐时可以把“网易云歌单名、歌曲名、歌手名”等安全摘要作为候选，不发送 Cookie 或账号凭据。

## 数据与隐私

- 平台凭据文件放在应用数据目录下的 `music-platforms` 子目录。
- 前端只拿到 `loggedIn`、`profile`、`message` 等状态字段。
- 歌单读取只返回脱敏摘要和必要平台 ID，不返回 Cookie、播放链接或用户本机路径。
- 歌词读取和播放 URL 获取由后端使用本机登录态完成，Cookie 不回传前端。
- 播放 URL 只保存在前端运行时内存中，不进入本地音乐库持久化。
- 后端检查登录状态时读取 Cookie 后立即发起网易云状态请求，不把 Cookie 回传给 Vue。
- 清除登录会删除本机凭据文件，并重置前端状态。

## 技术方案

- 后端使用 Rust 命令访问网易云二维码接口：
  - 创建二维码 key。
  - 生成本机二维码 SVG data URL。
  - 检查二维码扫码状态。
  - 登录成功后保存响应 Cookie。
  - 读取账号状态。
- 前端在“网易云”页签中控制二维码生命周期：
  - 用户点击“扫码登录”后创建二维码。
  - 每 2 秒轮询一次扫码状态。
  - 成功、过期、失败或离开窗口时停止轮询。
  - 组件卸载时清理轮询定时器。
- 歌单读取：
  - 前端调用 `list_netease_playlists` 获取当前账号歌单摘要。
  - 前端调用 `get_netease_playlist_detail` 获取单个歌单歌曲摘要。
  - 后端优先使用已保存登录态请求网易云官方接口，接口失败时使用兼容请求链路。
  - 详情列表限制展示数量，避免超大歌单拖慢窗口。
- 在线歌词和播放：
  - 前端调用 `read_netease_lyrics` 获取歌曲歌词，优先使用 YRC 逐字时间戳驱动沉浸歌词；没有 YRC 时使用 LRC，翻译歌词作为补充。
  - 前端调用 `get_netease_song_playback_url` 获取单首歌曲临时播放 URL。
  - 播放 URL 只创建当前播放用的临时曲目，不走本地导入和本地歌单保存流程。
  - 现有沉浸模式复用同一歌词窗口；网易云临时曲目加载在线歌词，本地曲目继续加载同名本地歌词。
