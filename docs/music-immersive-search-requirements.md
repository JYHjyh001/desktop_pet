# 沉浸模式音乐搜索需求计划

本文档记录沉浸模式新增顶部音乐搜索入口的实现计划。本功能只使用当前运行态搜索关键词、平台选择和平台返回的歌曲摘要，不保存用户歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 背景

当前沉浸模式主要依赖左侧播放列表切换本地、网易云和酷狗内容。用户希望参考 Mineradio 的顶部搜索体验，在沉浸模式正上方直接搜索在线歌曲，并能选择一个或多个音乐平台。

## 目标

1. 沉浸模式顶部新增搜索框，默认贴近并隐藏到屏幕顶边，鼠标悬停或聚焦时展开。
2. 搜索结果直接显示在搜索框下方，不跳转到普通音乐窗口。
3. 搜索平台选项放在搜索框下面，提供“全部 / 网易云 / 酷狗”。
4. 支持多选平台；“全部”表示同时搜索当前已接入的在线平台。
5. 点击搜索框以外区域后，搜索框取消选中状态并收起。
6. 搜索结果可直接播放；播放仍复用现有网易云和酷狗临时在线播放链路。

## 非目标

1. 不新增 QQ 音乐或其他平台后端接口。
2. 不下载、不缓存、不持久化在线音频。
3. 不把搜索关键词、结果、播放 URL、歌词文本、Cookie、token 或本机路径写入源码、文档示例或本地曲库。
4. 不绕过平台会员、版权、地区、DRM 或付费限制。
