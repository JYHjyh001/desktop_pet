# 沉浸模式只看舞台需求

本文档记录音乐沉浸模式新增“只看舞台”隐藏功能。本功能只调整运行态界面显示状态和交互层级，不保存用户歌曲路径、播放 URL、歌词内容、平台 Cookie、token、音频数据或本机运行历史。

## 目标

- 在沉浸模式中提供一键隐藏界面控件的模式，保留音乐视觉舞台与歌词舞台。
- 让用户专注观看星河漫游或地面 DJ 舞台的节奏变化。
- 保留可恢复界面的入口，避免进入只看舞台后无法操作。
- 默认主题和 `animal-island` 主题下视觉状态都可读、可点击。

## 范围

- 沉浸模式头部动作区新增“只看舞台/显示界面”切换。
- 开启后隐藏标题、播放列表、韵律面板、底部控制栏和空状态，保留歌词舞台。
- 开启后保留舞台拖拽、滚轮景深、自由镜头等舞台交互。
- 开启后右上角保留轻量眼睛图标恢复热区，鼠标移入或键盘聚焦时显示按钮，鼠标移开后隐藏。
- 只看舞台开启后支持按 `Esc` 退出并恢复完整沉浸界面。
- 播放列表和韵律面板的隐藏/恢复入口放在各自卡片上，以图标按钮呈现；隐藏后默认收进屏幕边缘，只在鼠标靠近或键盘聚焦时滑出。

## 不做

- 不修改音乐播放链路。
- 不保存新的歌曲、歌词、路径、平台凭据或播放 URL。
- 不改变现有舞台预设和主题参数含义。

## 验收

- 沉浸模式可一键进入只看舞台。
- 只看舞台时画面保留舞台视觉和歌词舞台，恢复按钮默认隐藏。
- 鼠标移到右上角热区或键盘聚焦时能显示恢复按钮，并能回到完整沉浸界面。
- 只看舞台时按 `Esc` 能回到完整沉浸界面。
- 播放列表和韵律面板可通过各自卡片上的图标隐藏，隐藏后保留贴边热区，鼠标靠近或键盘聚焦时小型图标卡片滑出用于恢复。
- 退出沉浸模式或进入迷你播放器时自动退出只看舞台。
- 默认主题和 `animal-island` 主题下恢复按钮清晰可点击。
- `npm run build` 通过。
- 隐私检查通过，不提交本机配置、密钥、用户路径、播放 URL 或打包产物。
