# AI 宠物音乐播放功能需求参考

本文档根据用户提供的音乐功能设计文本整理，用作后续逐步实现“宠物电台 / AI 音乐陪伴”功能的长期参考。

## 实现原则

- 音乐功能不是单纯播放器，而是 AI 桌宠的陪伴式音乐管家。
- 先完成可用的本地音乐播放能力，再逐步加入 AI 推荐、宠物动画联动、专注/睡眠/情绪模式和第三方音乐软件控制。
- 歌曲路径、播放列表、分类、标签、历史、存储目录都属于用户本机数据，不能写入源码、示例文档或仓库。
- 每次新增音乐 UI 都必须同时检查默认主题和 `animal-island` 主题。

### AI 回复规则

- [x] 当用户明确表达想听音乐、点播歌曲、或要求用音乐陪伴放松/睡觉/学习时，AI 可以调用音乐功能。
- [x] 通用 AI API 只接收标签、歌曲数量、收藏数量和最近播放数量等安全摘要，不上传歌曲路径。
- [x] 音乐播放必须由 AI 判断用户明确表达听歌、点播或控制音乐需求后才触发，本地关键词不直接决定播放。
- [x] 按歌名点播由 AI 语义判断；单独输入歌名、单纯情绪表达、讨论播放功能或代码需求时不触发。
- [x] 用户可关闭对话音乐联动，关闭后不调用音乐意图分类器，也不会打开或控制音乐播放器。
- [ ] AI 根据用户情绪、当前时间、聊天内容和音乐标签选择合适音乐。
- [x] 用户只说“放首歌”时，优先选择最近喜欢或常听的音乐。
- [x] 用户说“别放这首”时，跳过当前歌曲并降低类似歌曲推荐优先级。
- [ ] 用户说“这首不错”时，询问是否加入收藏，或提高歌曲权重。
- [x] 音乐推荐回复要简短、自然、有陪伴感。
- [x] 音乐控制回复作为普通 AI 对话生成，并遵循当前伴侣人设、系统提示词、伴侣附加规则、后置指令和好感度关系阶段。

## 第四阶段：宠物动作和状态联动

目标：播放音乐时桌宠有对应动作反馈。

### 音乐状态

- [ ] `music_idle`：未播放。
- [ ] `music_playing`：播放中。
- [ ] `music_paused`：暂停。
- [ ] `music_dance`：跳舞。
- [ ] `music_sleep`：睡眠音乐。
- [ ] `music_focus`：专注陪伴。
- [ ] `music_sad`：伤感陪伴。
- [ ] `music_happy`：开心律动。

### 动作反馈

- [ ] 播放中：轻轻晃动、点头、尾巴摆动。
- [ ] 暂停：坐下等待、眨眼。
- [ ] 切歌：转身、挥手、蹦一下。
- [ ] 收藏歌曲：开心表情、冒爱心。
- [ ] 音量变大：戴耳机、音符变多。
- [ ] 睡眠音乐：趴下、闭眼、呼吸动画。
- [ ] 热血音乐：跳舞、挥拳、兴奋。
- [ ] 伤感音乐：安静坐着、低头陪伴。

### 好感度联动

- [ ] 低好感度：回复普通，例如“已为你播放音乐。”
- [ ] 中好感度：回复自然，例如“好，我帮你放一首轻松的。”
- [ ] 高好感度：更有陪伴感，例如“你今天是不是有点累？我放首温柔点的歌陪你。”

## 第五阶段：特殊模式

### 情绪陪伴模式

- [ ] 识别开心、疲惫、难过、焦虑、孤独、兴奋、平静、生气等情绪。
- [ ] 根据情绪映射推荐标签。
- [ ] 自动播放对应歌曲或推荐歌单。
- [ ] 桌宠进入对应陪伴动作。

### 学习专注模式

- [ ] 播放纯音乐或白噪音。
- [ ] 隐藏歌词。
- [ ] 降低桌宠动作频率。
- [ ] 减少主动打扰。
- [ ] 定时提醒休息。
- [ ] 番茄钟联动。

### 睡眠模式

- [ ] 播放轻音乐、白噪音或雨声。
- [ ] 自动降低音量。
- [ ] 定时停止播放。
- [ ] 播放完当前歌曲后停止。
- [ ] 音量逐渐降低。
- [ ] 桌宠进入睡觉动画。

### 起床模式

- [ ] 定时播放音乐。
- [ ] 音量逐渐升高。
- [ ] 桌宠叫醒动画。
- [ ] 显示今日提醒。
- [ ] 播放元气歌单。

### 跳舞模式

- [ ] 用户手动开启。
- [ ] 快节奏音乐自动开启。
- [ ] AI 判断当前歌曲适合跳舞时开启。
- [ ] 增加音符粒子、节奏光圈、背景灯效。

### 剧情音乐模式

- [ ] 故事模式推进时根据剧情场景播放 BGM。
- [ ] 日常聊天：轻松 BGM。
- [ ] 伤感剧情：慢节奏钢琴。
- [ ] 约会剧情：温柔浪漫。
- [ ] 战斗剧情：热血音乐。
- [ ] 悬疑剧情：低沉氛围。
- [ ] 睡前剧情：白噪音或轻音乐。
