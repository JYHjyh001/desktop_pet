# 酷狗播放链路代理化需求计划

## 背景

当前酷狗在线播放链路在点击播放时获取一次临时播放地址，并交给前端 `audio` 直接播放。部分歌曲可以从开头顺序播放，但拖动到后半段时会触发读取失败，常见原因包括临时地址过期、CDN Range 请求受限、只返回试听片段、登录态或设备参数不完整、会员/版权/地区限制等。

## 隐私和合规边界

- 酷狗 Cookie、token、设备标识、播放 URL 只允许保存在本机运行态或用户本机应用数据目录中，不写入源码、文档示例或提交记录。
- 前端不展示、不持久化酷狗真实播放 URL、Cookie、token 或设备标识。
- 本功能只改善用户已授权登录态下的播放稳定性，不绕过会员、版权、地区、DRM 或付费限制。
- 代理日志和错误提示不得输出完整播放 URL、Cookie、token 或用户本机路径。
- 用户账号本身有会员不等于第三方接口一定能拿到与官方客户端一致的完整播放授权；设备注册、风控、网页/客户端播放环境差异需要单独诊断。

## 目标

1. 前端播放酷狗歌曲时使用本机代理地址，不再直接播放酷狗临时 URL。
2. 本机代理支持浏览器拖动进度产生的 `Range` 请求。
3. 当 CDN 请求失败时，后端可以刷新酷狗临时播放链接并重试同一个请求。
4. 前端保留现有搜索、歌单、沉浸模式播放入口，尽量减少用户操作变化。
5. 错误提示区分“代理读取失败”“链接刷新失败”“可能试听片段或版权限制”等情况。

## 第一阶段范围

- 新增酷狗本机播放代理服务器，绑定 `127.0.0.1` 随机端口。
- 播放时创建运行态播放会话，返回 `http://127.0.0.1:<port>/kugou/play/<sessionId>`。
- 播放会话只保存在内存中，包含歌曲 hash 候选、专辑音频 ID 和当前临时播放 URL。
- 代理转发 `Range`、`User-Agent`、`Referer` 等基础请求头。
- 代理遇到非成功状态或请求失败时刷新播放 URL 并重试一次。
- 代理分块转发音频流，避免整段音频请求被固定总超时中断。
- 播放器拖动进度、切歌或重试时主动取消旧 Range 连接属于正常行为，代理应静默处理 Windows `10053/10054` 等客户端断开错误，不刷新链接、不刷屏日志。
- 播放地址获取阶段产生的 Range 预检结果复用到代理会话，避免注册代理时重复请求 CDN，降低在线切歌等待。
- 前端继续使用现有 `audio` 播放控件，拖动逻辑保持不变。
- 前端监听 `waiting` 和 `stalled`，在线音源长时间无数据时刷新当前运行态播放链路，并尝试从原播放进度继续。
- 播放前参考第三方酷狗 API 实现补充本机设备注册：调用酷狗设备注册接口获取 `dfid`，只写入本机平台凭据，不返回前端展示。
- 登录态播放地址候选新增 `/v5/url` 链路，优先使用“设备注册 + `/v5/url`”尝试，再回退到现有 `/v6/priv_url` 和旧播放接口。

## 后续增强

- 为网易云复用同类代理框架。
- 增加代理状态诊断命令，只返回脱敏状态和错误类型。
- 对官方客户端专用设备授权、风控授权或网页/客户端外部播放兜底做可行性评估；不得绕过会员、版权、地区、DRM 或付费限制。

## 验收清单

- [x] 酷狗搜索结果播放返回本机代理地址。
- [x] 酷狗我的歌单播放返回本机代理地址。
- [x] 拖动进度时代理能收到并转发 Range 请求。
- [x] 临时 URL 请求失败时后端会刷新链接并重试。
- [x] 代理对播放器主动取消的旧连接静默处理，避免 `os error 10053` 刷屏。
- [x] 音频流转发只限制连接建立时间，不再用整段 30 秒总超时限制。
- [x] 音频流转发增加上游读取超时，酷狗 CDN 已连接但长时间不返回数据时会产生明确断流错误。
- [x] 播放地址预检结果复用到本机代理会话，减少酷狗切歌时的重复 Range 探测。
- [x] 前端对在线音源 `waiting/stalled` 做受控恢复，刷新运行态播放链路并尝试从原进度继续；刷新后验证播放进度是否真实推进，连续失败时标记当前运行态不可播放并自动尝试下一首。
- [x] 播放链接会做开头和后半段 Range 预检，识别疑似试听片段并停止播放。
- [x] 登录态播放前补充酷狗设备注册，并将 `/v5/url` 作为优先播放链接候选。
- [x] 普通接口返回需要付费且登录态接口只返回试听片段时，前端给出会员/付费/版权授权边界提示。
- [x] 前端不接收酷狗真实播放 URL。
- [x] 默认主题和 `animal-island` 主题中的错误提示继承现有状态样式并保持可读。
- [ ] 构建通过，隐私关键词扫描无真实密钥或隐私数据。
