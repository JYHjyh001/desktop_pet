# 沉浸模式歌词参数可调需求

状态：已完成。

## 目标

在音乐沉浸模式中补充直接面向歌词可读性的参数调节，让用户可以在不同舞台、主题和屏幕尺寸下调整歌词大小、位置、远近和上下句弱化程度。后续根据用户反馈，宽度和唱词进度强度调节已移除。

## 范围

- 仅调整沉浸模式歌词呈现参数。
- 保留单一歌词舞台表现、倾角和溢光；移除歌词舞台预设、景深、宽度、进度、歌词光粒、镜头绑定和鼓点溢光调节。
- 新增参数只作为本机视觉偏好保存，不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。
- 默认主题和 `animal-island` 主题都需要保持控件可读、布局稳定。

## 参数

- 字号：控制当前歌词和上下句整体字号倍率，范围扩大到约 66% 到 138%。
- 位置：控制歌词舞台垂直偏移，范围扩大到约上 260px 到下 260px。
- 远近：控制歌词舞台 Z 轴距离和轻量空间缩放，范围为约远 180px 到近 180px，辅助缩放约 96% 到 104%，避免与字号调节过于相似。
- 弱化：控制上一句和下一句透明度。

## 行为规则

- 参数即时生效。
- 提供“重置歌词”按钮恢复默认外观参数。
- 降低动态开启时仍保留静态字号、位置、远近和透明度调整。

## 验证

- [x] `animal-island` 主题下歌词参数控件继承主题样式并保持可读。
- [x] 调整参数、刷新窗口后设置可以恢复。

## 实现记录

- 在歌词舞台卡片中保留字号、位置、远近和弱化四个滑杆，并提供“重置歌词”按钮。
- 字号会参与歌词行数估算和主/副歌词字号计算，避免长句调整后与上下句重叠。
- 位置、远近和上下句透明度通过 CSS 变量即时作用到沉浸歌词舞台；远近以 Z 轴位移为主，只保留轻量整体缩放，避免和字号调节过于相似；宽度和进度调节已固定为默认表现。
- 点击重置时恢复默认歌词外观。
- 新增设置只保存为本机视觉数值，不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。
