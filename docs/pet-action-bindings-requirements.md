# 宠物操作按键绑定功能需求计划

本文档规划桌面宠物鼠标操作的可配置绑定。所有绑定只保存动作枚举，不保存用户本机路径、Codex 任务内容、窗口标题、进程信息或隐私数据。

## 背景

当前宠物窗口的单击、双击和右键行为在前端写死：

- 单击：根据 Codex 完成提醒决定是否聚焦 Codex，否则执行抽屉相关行为。
- 双击：切换抽屉。
- 右键：打开宠物菜单。

用户希望这些操作可以在设置中重新绑定，方便按自己的使用习惯调整。

## 目标

1. 在设置页提供“宠物操作绑定”配置。
2. 支持配置单击、双击和右键动作。
3. 默认行为保持兼容现有使用习惯：
   - 单击：Codex 完成时打开已启动的 Codex，否则打开抽屉。
   - 双击：切换抽屉。
   - 右键：打开宠物菜单。
4. 配置保存到用户本机运行时 `config.json`，不写入源码示例或仓库数据文件。
5. 默认主题和 `animal-island` 主题都能继承现有设置表单样式。

## 动作范围

本阶段支持以下动作：

- Codex 完成优先，否则打开抽屉。
- 切换抽屉。
- 打开抽屉。
- 打开宠物菜单。
- 打开宠物聊天。
- 打开故事模式。
- 打开音乐播放器。
- 无操作。

## 非目标

1. 不实现系统级全局快捷键注册。
2. 不捕获任意键盘组合键。
3. 不启动 Codex，只聚焦已打开的 Codex 窗口。
4. 不保存真实 Codex 窗口信息、用户项目路径或任务正文。

## 验收标准

1. 设置页可以分别修改单击、双击和右键动作。
2. 保存设置后，宠物窗口不重启也能收到并应用新绑定。
3. 旧配置缺少新字段时自动使用默认绑定。
4. Codex 未启动或没有可聚焦窗口时，默认单击动作仍回退打开抽屉。
5. `npm run build` 通过。
