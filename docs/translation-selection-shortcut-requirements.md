# 划选翻译快捷键功能需求计划

状态：已实现。

本文档规划独立翻译功能的快捷键增强。该功能允许用户在其他应用中选中一段文字后，按下用户绑定的全局快捷键触发翻译，并通过桌宠气泡显示短译文。功能仍属于翻译模块，不接入宠物聊天、记忆、好感度、故事或音乐链路。

## 目标

1. 支持用户配置“划选翻译快捷键”，默认 `Ctrl+Alt+T`，可改为 `F3` 或其他组合键。
2. 快捷键触发后读取当前系统选中文本，并调用现有独立 `translate_text` 翻译命令。
3. 翻译结果通过桌宠气泡显示短结果，较长结果截断显示。
4. 点击或使用完整翻译窗口查看长文本仍由独立翻译窗口承载。
5. 不保存选中文本、译文、翻译历史、窗口标题或来源应用信息。
6. 默认主题和 `animal-island` 主题下气泡继续使用现有桌宠气泡样式。

## 非目标

1. 不做 OCR、截图翻译或图片翻译。
2. 不直接读取其他应用私有控件内容。
3. 不保存划选翻译历史。
4. 不把选中文本同步到宠物聊天、记忆、故事、音乐或 Codex 状态。
5. 不保证所有应用都能读取选中文本；无法复制的控件需要显示失败提示。

## 技术方案

1. 使用 Tauri 全局快捷键插件注册快捷键。
2. 快捷键配置保存在用户本机运行时 `config.json` 的 `shortcut.translateSelection`。
3. 桌宠窗口启动后读取配置并注册快捷键；设置保存后通过事件通知桌宠窗口重注册。
4. 快捷键触发时调用后端 `translate_selected_text`。
5. Windows 后端执行：
   - 保存当前剪贴板文本。
   - 模拟 `Ctrl+C`。
   - 等待短时间让目标应用写入剪贴板。
   - 读取剪贴板文本。
   - 恢复原剪贴板文本。
   - 调用现有独立翻译函数。
   - 用 `show_pet_bubble` 展示结果或错误。
6. 非 Windows 暂时返回明确不支持提示。

## 隐私边界

1. 选中文本只存在于本次翻译调用的内存中。
2. 恢复剪贴板时只恢复文本内容；非文本格式剪贴板第一阶段不保证完整恢复。
3. 错误提示不得输出完整选中文本、API Key、Base URL 查询参数、窗口标题或来源应用信息。
4. 如果用户使用在线 AI 服务，选中文本会发送到用户配置的 AI 接口；如果使用本机 Ollama，则走用户配置的本机服务地址。

## 设置项

新增字段：

```text
shortcut.translateSelection: string
```

默认值：

```text
Ctrl+Alt+T
```

UI 位置：

1. 抽屉设置中的“窗口/操作”相关区域。
2. 与宠物单击、双击、右键绑定放在同一组。
3. 提示用户 `F3` 可能与其他软件查找功能冲突。

## 验收标准

1. 默认快捷键 `Ctrl+Alt+T` 可注册成功。
2. 用户改成 `F3` 后保存设置，桌宠窗口无需重启即可重注册。
3. 在普通文本编辑器中选中文本后按快捷键，可以通过气泡看到译文。
4. 没有选中文本或目标应用不允许复制时，气泡显示可理解错误。
5. 快捷键冲突或格式无效时，设置保存不崩溃，气泡或控制台显示可理解错误。
6. 翻译请求不写入宠物聊天记录、不写入宠物记忆、不修改好感度。
7. `npm run build`、`cargo check` 通过。
