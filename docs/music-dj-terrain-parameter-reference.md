# 地面 DJ 参数说明与修改口径

本文档记录沉浸音乐“地面 DJ”柱阵地形的主要视觉参数，方便后续用清晰分类描述要修改的效果。本文档只记录前端视觉参数，不记录用户歌曲路径、播放 URL、歌词文本、平台 Cookie、token、音频数据或本机运行历史。

## 快速描述模板

以后可以按下面格式提需求，能减少歧义：

- `地面 DJ / 中心大片波 / 速度：把从中心扩散的大片突起圈再加快 20%，随机小波不动。`
- `地面 DJ / 中心大片波 / 高度：中心扩散那圈柱子抬得更高，但颜色亮度不变。`
- `地面 DJ / 随机触发点 / 速度：随机低频小波慢一点，中心大片波不动。`
- `地面 DJ / Kick 抬升 / 强度：鼓点命中时中间柱子突然抬升更明显，扩散速度不变。`
- `地面 DJ / 柱阵布局 / 密度：柱子更密，但圆盘大小不变。`
- `地面 DJ / 主题材质 / animal-island：动物岛主题的柱顶更暖，背景别更亮。`
- `地面 DJ / 镜头 / 视距：默认镜头拉远一点，拖动和自由镜头不动。`

## 关键不要混淆

| 分类 | 代表现象 | 当前实现 | 不应误改 |
| --- | --- | --- | --- |
| 中心大片波 | 从舞台中心向外扩散的一整圈突起地面 | 独立 `uCenterPulseData`，不进入普通随机波纹队列 | 不要改 `TERRAIN_PULSE_SPEED` |
| 随机触发点波纹 | 在不同位置随机冒出的局部小波 | `uRipple*` 队列，类型是 `pulse/snare/spark` | 不要改 `TERRAIN_CENTER_PULSE_SPEED` |
| Kick 抬升 | 鼓点命中时中心柱子突然顶起 | `terrainKickEnvelope` 只作用中心和内圈 | 不等同于扩散速度 |
| 慢速地形流动 | 地面整体有缓慢纹理和高度流动 | shader 里的 `slowFlow/radialPhase/ringRipple` | 不等同于中心大片波速度 |

## 现有舞台滑杆

位置：`src/windows/MusicWindow.vue` 的 `djStageTuningOptions`，运行时传入 `src/components/MusicWebglStarfield.vue`。

| UI 名称 | key | 范围 | 默认 | 主要影响 | 修改口径 |
| --- | --- | ---: | ---: | --- | --- |
| 高度 | `height` | `0.25 - 2.4` | `1` | 柱体最大高度，参与 `maxHeight` | “柱子整体更高/更矮” |
| 响应 | `response` | `0.2 - 2.4` | `1` | shader 内部时间倍率，影响地形流动响应 | “地形流动更快/更稳” |
| 密度 | `density` | `0.35 - 1.7` | `1` | DJ 柱阵网格数量，会重建实例几何 | “柱子更密/更稀” |
| 波峰 | `wave` | `0.2 - 2.4` | `1` | 扩散波峰强度、波面宽度和衰减倍率 | “波峰更厚/更弱” |
| 触发 | `trigger` | `0.25 - 2.4` | `1` | 低频、中频、高频触发敏感度和速度倍率 | “更容易触发/别那么频繁” |
| 视距 | `camera` | `0.55 - 1.65` | `1` | 默认镜头距离 | “镜头拉近/拉远” |

## 中心大片地面突起波

这是这次确认“对了”的参数组。关键词是“从中心扩散的大片地面突起”“中心那圈突起地面”“固定中心向外推开的环”。

位置：`src/components/MusicWebglStarfield.vue`

| 参数 | 当前值 | 作用 | 修改口径 |
| --- | ---: | --- | --- |
| `TERRAIN_CENTER_PULSE_SPEED` | `24` | 中心大片波基础扩散速度 | “中心大片波速度改到 X” |
| `terrainCenterPulseSpeedScale` | 音乐驱动，约 `0.8 - 1.58` | 鼓点越强，中心波实际速度越快 | “强低频时速度变化小一点/大一点” |
| `maxAge` | 默认约 `3.65s`，降低动态约 `3.25s` | 中心波最长可见时间 | “波消失慢一点/快一点” |
| `TERRAIN_PULSE_WIDTH` | `0.34` | 中心波复用的基础波面宽度 | “中心波更厚/更薄” |
| `TERRAIN_PULSE_FADE_DISTANCE` | `5.15` | 中心波复用的基础拖尾衰减 | “波拖尾更长/更短” |
| `safeStrength` 上限 | `1.08` | 中心波强度上限 | “中心波更猛/更克制” |
| 触发门槛 | `safeStrength <= 0.08` 时忽略 | 避免弱噪声触发中心波 | “弱低频也要触发/减少误触发” |
| 中心波内侧填充 | `centerFill` | 波峰内侧保留较低隆起，避免中心相对凹陷 | “中心不要凹/内侧填充多一点” |

实际速度公式：

```ts
实际中心扩散速度 =
  TERRAIN_CENTER_PULSE_SPEED *
  (0.9 + waveTuning * 0.08) *
  terrainCenterPulseSpeedScale
```

默认 `waveTuning = 1` 时：

```txt
基础实际速度约 24 * 0.98 = 23.52
正常模式大致范围约 18.82 - 37.16
```

注意：

- 如果只说“中心大片波快一点”，优先改 `TERRAIN_CENTER_PULSE_SPEED`。
- 如果说“波更厚”，优先改中心波宽度相关公式，不要改随机波纹速度。
- 如果说“中心柱子突然抬升更明显”，优先改 Kick 抬升，不是改中心波速度。
- 如果说“中间凹进去”，优先改 `centerFill` 的范围或抬升强度，不要改中心波速度。

## 随机触发点波纹

关键词是“随机冒出来的小波”“不是从中心出来的波”“局部触发点”。

位置：`src/components/MusicWebglStarfield.vue`

| 类型 | 当前基础速度 | 当前基础宽度 | 当前拖尾 | 触发来源 | 修改口径 |
| --- | ---: | ---: | ---: | --- | --- |
| `pulse` | `3.05` | `0.34` | `5.15` | 低频、bass、beat | “随机低频小波快/慢” |
| `snare` | `4.15` | `0.16` | `3.2` | 中频、lowMid、mid | “中频波快/慢” |
| `spark` | `4.45` | `0.12` | `2.65` | 高频、treble | “高频闪波快/慢” |

随机波实际速度公式：

```ts
随机波实际速度 =
  kindBaseSpeed *
  (0.9 + waveTuning * 0.08) *
  ripple.speedScale
```

随机波位置范围：

| 类型 | 位置范围口径 |
| --- | --- |
| `pulse` | 中心到近中圈随机点，`ring = rand^0.72 * 0.62` |
| `snare` | 中圈到外圈随机点，`ring = 0.22 + rand * 0.68` |
| `spark` | 外圈随机点，`ring = 0.48 + rand * 0.48` |

不要混淆：

- “中心大片波”不使用这组速度。
- “随机低频小波”才使用 `TERRAIN_PULSE_SPEED = 3.05`。
- 以后如果你说“其他随机点不要变”，就不改这一节。

## 频谱触发器

这组决定什么时候产生 `pulse/snare/spark`。有实时频谱数据时优先走频谱通量触发器；没有足够频谱数据时走 fallback 触发。

### 频谱通量触发

| 类型 | 频段比例 | 灵敏度 | 冷却 | 强度倍率 | 修改口径 |
| --- | --- | ---: | ---: | ---: | --- |
| `pulse` | `0.002 - 0.008` | `0.85` | `0.24s` | `7.2` | “低频更容易/更难触发” |
| `snare` | `0.092 - 0.235` | `0.6` | `0.42s` | `5.8` | “中频触发多一点/少一点” |
| `spark` | `0.235 - 0.42` | `0.48` | `0.56s` | `5.2` | “高频闪点更频繁/更克制” |

### fallback 触发

| 类型 | 当前冷却 | 降低动态冷却 | 触发条件口径 |
| --- | ---: | ---: | --- |
| bass / `pulse` | `0.2s` | `0.36s` | beat 上升或 bassPush + energyRise |
| mid / `snare` | `0.4s` | `0.64s` | midPush + energyRise |
| spark | `0.52s` | `0.82s` | sparkPush 且高频明显或 beat 上升 |

`trigger` 滑杆会影响冷却和门槛：

```txt
cooldownScale = 1 / sqrt(trigger)
thresholdScale = 1 / trigger
```

所以：

- `trigger` 越大，越容易触发，冷却越短。
- `trigger` 越小，越不容易触发，冷却越长。

## Kick 中心冲击抬升

关键词是“鼓点命中时中间柱子突然升高”“中心柱子瞬间顶一下”“不是扩散速度”。

| 参数 | 当前值 | 作用 | 修改口径 |
| --- | ---: | --- | --- |
| `TERRAIN_KICK_MIN_IMPULSE` | `0.46` | 最小 Kick 冲击强度 | “弱鼓点也顶起来/弱鼓点别顶” |
| `strength * 0.88` | `0.88` | 由中心波强度转 Kick 冲击 | “中心冲击更猛/更柔” |
| envelope 初始写入 | `impulse * 0.68` | 让中心柱子立即抬起 | “突然感更强/更弱” |
| `TERRAIN_KICK_TARGET_DECAY_RATE` | `10` | Kick 目标衰减速度 | “回落快/慢” |
| `TERRAIN_KICK_RESPONSE_RATE` | `26` | envelope 跟随速度 | “冲击更利落/更钝” |

Shader 高度相关：

```glsl
kickLift = kickImpact * (centerCore * 0.54 + innerBand * 0.16) * (0.9 + uWave * 0.08);
kickHeight = kickImpact * (centerCore * 0.18 + innerBand * 0.05) * uMaxHeight * (0.32 + uWave * 0.04);
```

修改口径：

- “中间柱子突然抬得更高”：改 `centerCore * 0.54`、`centerCore * 0.18` 或 Kick impulse。
- “内圈也跟着抬”：改 `innerBand * 0.16`、`innerBand * 0.05`。
- “回落慢一点”：降低 decay rate。

## 慢速地形流动和微动

这组不是中心大片波速度。它影响柱阵表面的慢速流动、尾部起伏、局部尖峰和空闲微地形。

| shader 项 | 当前时间倍率 | 视觉作用 | 修改口径 |
| --- | ---: | --- | --- |
| `rippleTail` | `time * 0.34` | 扩散波尾部起伏 | “波尾更活/更稳” |
| `angularFlow` | `time * 0.18` / `0.14` | 角向缓慢流动 | “圆盘纹理流动更快/慢” |
| `radialPhase` | `time * 0.52` | 中频径向流 | “地面整体扫描更快/慢” |
| `slowFlow` | `time * 0.32` | 低中频慢速起伏 | “背景地形呼吸更明显/更静” |
| `spikeGate` | `time * 5.8` | 少量尖峰闪动 | “尖峰闪得更快/慢” |
| `microSpark` | `time * 8.4` | 极少数高频微闪 | “细小闪点更多/更少” |
| `ringRipple` | `time * 0.32` | 很轻的环形底纹 | “底纹波动更明显/更弱” |

Shader 时间还会乘 `response`：

```glsl
time = uTime * (0.72 + clamp(uResponse, 0.2, 2.4) * 0.38) * motion;
```

修改口径：

- “中心那圈扩散速度”不要动本节，动 `TERRAIN_CENTER_PULSE_SPEED`。
- “整个地面流动感更快/更慢”才动本节或 `response`。

## 柱阵布局和密度

关键词是“柱子更多/更少”“圆盘更大/更小”“边缘不要截断”“中心位置”。

| 参数 | 当前值 | 作用 | 修改口径 |
| --- | ---: | --- | --- |
| `DJ_TERRAIN_CENTER_Z` | `-3.28` | DJ 圆盘和相机观察中心的 Z 锚点 | “舞台中心前后移动” |
| `DJ_TERRAIN_GROUND_Y` | `-1.86` | 柱阵地面基准高度 | “整片地面上/下移” |
| `footprint` | `12.2` | DJ 圆盘基础尺寸 | “圆盘整体更大/小” |
| `djGridExtent` | `1.2` | 采样范围扩展 | “边缘缓冲更宽/窄” |
| `djOuterLimit` | `1.08` | 圆盘裁切半径 | “圆盘边缘更圆/更收” |
| `baseSize` | `spacing * 1.015` | 单个柱体宽度 | “柱子之间缝更大/更小” |
| 默认 gridSize | `176` | 非降低动态的基础网格 | “默认柱子数量” |
| 降低动态 gridSize | `120` | 降低动态下的基础网格 | “降低动态也更密/更稀” |
| gridSize 上限 | `300` | 性能保护上限 | “密度上限再放宽” |

密度公式：

```ts
gridSize = round(clamp(baseSize * density, minSize, maxSize))
```

注意：

- `density` 滑杆会重建几何，影响性能。
- 想“更细腻”优先加密度；想“更像实体块”优先加柱体宽度。

## 高度合成

关键词是“整体柱子高度”“波峰高度”“空闲时地面不要太平”“最高别顶太满”。

| 参数/公式 | 当前值 | 作用 |
| --- | ---: | --- |
| `terrainMaxHeight('dj')` | `1.34` | DJ 预设基础最大高度 |
| `uBaseHeight` | `0.064` | 基础地台高度 |
| `maxHeight` | `1.34 * (0.58 + intensity * 0.24) * height` | 实际最大高度基准 |
| `terrainEnergy` 上限 | `1.25` | 整体音乐高度能量上限 |
| `rippleEnergy` 上限 | `1.18` | 波纹高度能量上限 |
| `rippleHeight` | `pow(rippleEnergy, 0.82) * uMaxHeight * (0.24 + uWave * 0.08)` | 扩散波高度 |
| `height clamp` | `0.006` 到 `uMaxHeight * 1.18 + 0.1` | 最终柱体高度限制 |

修改口径：

- “整体都高一点”：改 `height` 滑杆或 `terrainMaxHeight('dj')`。
- “只有波经过时更高”：改 `rippleHeight`。
- “空播放时也有地形”：改 `idleRelief`。
- “最高不要顶太满”：改最终 `height clamp`。

## 波纹可见性和颜色参与

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| 中心波发光 | `centerWave * 0.94` | 中心大片波的亮度贡献 |
| 中心波抬升 | `centerWave * 0.42` | 中心大片波的高度贡献 |
| 中心波内侧填充发光 | `centerFill * 0.28` | 波峰内侧低隆起的亮度贡献 |
| 中心波内侧填充抬升 | `centerFill * 0.18 - 0.22` | 波峰内侧低隆起的高度贡献 |
| 普通 `pulse` 发光 | `wave * 0.94` | 随机低频小波亮度 |
| 普通 `pulse` 抬升 | `wave * 0.42` | 随机低频小波高度 |
| `snare` 发光/抬升 | `0.76 / 0.2` | 中频波可见性 |
| `spark` 发光/抬升 | `0.62 / 0.16` | 高频小闪波可见性 |

修改口径：

- “中心波看得见但别太高”：提高发光，降低抬升。
- “中心波更像地面突起，不要只是亮”：提高抬升，控制发光。
- “中心波出去后中间凹进去”：提高中心波内侧填充抬升或加宽填充范围。
- “随机小波太抢眼”：只降低普通 `pulse/snare/spark`，不动中心波。

## 修改时的默认验证步骤

这类前端视觉参数修改后，默认按以下方式验证：

1. 先读取 `docs/RELEASE_PRIVACY_CHECKLIST.md`。
2. 改参数和同步本文档或对应需求文档。
3. 执行 `npm run build`。
4. 检查默认主题和 `animal-island` 主题下地面 DJ 是否正常渲染。
5. 如果要重启桌宠，按项目规则执行 `npm run tauri:build`，再启动 `src-tauri\target\release\pet_drawer.exe`。
6. 提交前检查 `git status --short`、`.gitignore` 和疑似密钥关键词扫描结果。
