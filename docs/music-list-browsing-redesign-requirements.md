# 音乐歌曲列表浏览区扩展需求

本文档记录音乐播放普通窗口中歌曲列表显示区域的扩展设计与验收要求。用户本机歌曲路径、平台凭据、播放历史、播放 URL、导入资源和搜索结果不得写入本文档或源码示例。

## 背景

当前音乐普通窗口已经包含本地音乐、网易云、酷狗、搜索、歌单摘要、歌词和播放控制。默认窗口尺寸偏窄，普通模式下播放区、筛选区和歌曲列表上下挤压，用户查找歌曲时可见行数较少。

## 目标

1. 扩大普通音乐窗口的歌曲浏览可用空间。
2. 让默认普通窗口在桌面环境下使用播放控制区和歌曲内容区并列布局。
3. 增加列表优先状态，便于集中查找歌曲。
4. 保持本地音乐、网易云、酷狗的现有数据边界和播放逻辑不变。
5. 默认主题和 `animal-island` 主题都要适配新增按钮、布局状态和列表密度。

## 本轮范围

- 调整普通音乐窗口默认尺寸。
- 调整普通窗口响应式断点，让宽版窗口使用双栏工作台。
- 新增列表优先切换按钮。
- 普通模式左侧播放工作台增加浏览辅助区，展示喜欢、最近、队列和下一首摘要，减少左下角空白。
- 列表优先时改为顶部播放栏加全宽歌曲内容区，不再保留左侧播放工作台。
- 优化本地歌曲列表和平台歌曲列表的行高、滚动区域和筛选区布局。
- 网易云和酷狗搜索结果支持按页加载更多，平台歌曲列表不再使用过小的内层固定高度。
- 网易云和酷狗“我的歌单”歌曲详情支持按页继续加载，不再只显示首批摘要。
- 平台歌单播放到当前已加载页末尾时，优先自动加载下一页歌曲，再继续顺序播放。

## 不在本轮范围

- 不修改音乐文件导入、存储目录、metadata 读取、歌词读取和在线播放接口。
- 不新增真实封面抓取或外部识别服务。
- 不保存网易云、酷狗搜索结果到本地音乐库。
- 不提交用户本机音乐路径、账号凭据、播放地址或运行历史。

## 验收标准

- `npm run build` 通过。
- 普通音乐窗口打开后，本地歌曲列表可见区域明显增大。
- “列表”按钮可在普通模式下切换列表优先状态。
- 列表优先状态下顶部播放栏仍可播放、暂停、切歌、拖动进度和调节音量。
- 列表优先状态下歌曲搜索、分类、标签筛选和清空按钮仍可用。
- 普通模式左侧播放工作台底部不再出现明显空白。
- 网易云和酷狗的搜索结果、歌单歌曲列表仍可滚动浏览。
- 网易云和酷狗搜索结果显示已加载数量和总数，并可继续加载后续结果。
- 平台歌曲列表由右侧内容区统一滚动，不因内层列表高度过小而隐藏后续结果。
- 网易云和酷狗“我的歌单”歌曲详情显示已加载数量和总数，存在后续歌曲时显示“加载更多”。
- 加载更多歌单歌曲时保留已加载列表，不回到空态或覆盖当前列表。
- 平台歌单顺序播放接近已加载页末尾时，不因播放上下文仍停留在首批歌曲而停止。
- 默认主题和 `animal-island` 主题下新增布局无明显重叠、溢出或不可读文本。
