# 在线音乐播放音质需求计划

## 背景

当前本地音乐会直接播放用户导入的原始文件，音质由文件本身决定。网易云在线播放固定请求标准音质，酷狗在线播放部分接口固定请求 `high`，且界面没有展示平台实际返回的音质、码率或文件类型，用户无法判断当前是否为最高可用音质。

## 目标

1. 在线音乐新增按平台区分的音质偏好，默认根据当前平台显示对应音质分类。
2. 网易云按网易云音质偏好请求播放地址，列表显示超清母带、沉浸环绕、高清环绕、Hi-Res、无损 SQ、极高 HQ 和标准档位。
3. 酷狗按酷狗音质偏好请求播放地址，列表显示蝰蛇母带音质、蝰蛇超清音质、蝰蛇HIFI音质、蝰蛇全景声2.0、Hi-Res 音质、无损音质、高品音质和标准音质。
4. 不同平台的音质偏好分开保存；切换平台时显示该平台上次选择的音质，不把酷狗档位直接套用到网易云请求。
5. 当前播放信息展示平台实际返回的音质、码率、格式或大小摘要。
6. 音质偏好只保存枚举值，不保存播放 URL、Cookie、token、设备标识或用户本机路径。

## 非目标

1. 不绕过会员、版权、地区、DRM 或付费限制。
2. 不读取或复用酷狗、网易云官方客户端的私有缓存。
3. 不把平台真实播放 URL、账号凭据、用户本机路径写入源码或文档。

## 验收清单

- [x] 音乐设置中可以选择在线播放音质偏好。
- [x] 音质列表会根据当前网易云、酷狗或通用状态动态切换分类。
- [x] 网易云不再固定请求标准音质，最高可用会按平台返回逐级回退。
- [x] 酷狗 `/v5/url` 不再固定只请求 `high`，会按偏好尝试多个质量候选。
- [x] 当前播放信息展示实际返回的音质摘要。
- [x] 默认主题和 `animal-island` 主题下音质控件可读、可点击且不挤压布局。
- [x] 不保存播放 URL、Cookie、token、设备标识或用户本机路径到源码、文档或本地曲库。
