# 沉浸音乐舞台预设视觉身份需求计划

## 背景

当前沉浸音乐舞台已经从“频谱、线条、波纹”三组控件改为整体舞台预设，但不同预设之间仍然共享较多星尘、星云和节拍点云，导致“默认舞台、电影脉冲、长播 DJ、纯歌词场”看起来都像星河效果的变体。用户期望每个舞台都有自己的特点，并明确提出宇宙星河粒子效果应该属于“星河漫游”；其他舞台可参考 Sonic Topography 的声音地形、频段驱动和舞台化视觉思路，但不得复制第三方代码、资源或受限实现。

## 目标

1. 只保留“星河漫游”和“地面 DJ”两个可见舞台预设。
2. “星河漫游”保持高密星尘、星云旋臂和空间漂浮感，不创建或显示地面柱体。
3. “地面 DJ”突出地面 EQ 柱阵、扫描轨迹和稳定长播动势。
4. 保持 WebGL 渲染轻量，不引入大型第三方可视化引擎，不上传音频、路径或歌词数据。

## 参考原则

- 仅参考 Sonic Topography 的高层视觉原则：音频频段驱动 3D 地形、高频驱动闪烁、节拍驱动局部冲击、歌词作为固定前景层。
- 不复制 Sonic Topography 的源码、shader、资源、字体、素材或受限许可内容。
- 本项目继续使用已有 `MusicWebglStarfield` 和舞台预设枚举完成改造；星河漫游保留原星河粒子层，地面 DJ 使用自研 `InstancedMesh` 柱体地形。

## 功能范围

### 预设定义

- 星河漫游：高密星尘、星云旋臂、流星轨迹和缓慢漂浮，强调空间纵深。
- 地面 DJ：地面 EQ 柱阵、扫描线、节奏阵列、轨迹流动，强调一列列柱子跟随音乐频段起伏。

### 性能约束

- 地面 DJ 减少星尘和星云粒子预算，用柱体地形替代泛粒子堆叠。
- 保持 GPU `Points + ShaderMaterial` 路线，减少 CPU 每帧参与。
- 降低动态模式下继续使用更少粒子和更小运动幅度。

### 主题要求

- 默认主题下预设卡片和 WebGL 颜色继承现有沉浸主题调色板。
- `animal-island` 主题下预设卡片继续继承已有纸感、暖色、圆角和文本对比样式。
- 新增或调整的舞台文案不得出现本机路径、歌曲路径、账号信息或私有配置。

## 实施步骤

1. 更新沉浸舞台预设卡片的名称、说明、色板和指标文案，让用户能直接理解每个舞台的视觉身份。
2. 调整 `MusicWebglStarfield` 各预设的粒子预算，让星河预设拥有最高星尘/星云密度，地面 DJ 不绘制粒子点层。
3. 新增 WebGL 地面 DJ 柱体层，使用实例化方块形成声音地形，由低频、中频、高频、整体音量和节拍共同驱动高度、颜色与亮度；柱体使用当前沉浸主题调色板、专用 shader 和实例颜色缓冲输出不透明顶面与侧面，并限制亮度增益，避免被内置材质混合成黑色剪影或被高光冲成白片。
4. 地面 DJ 柱阵参考 Sonic Topography 的二维声音地形思路：使用密集圆形布局，低频、节拍、中频和高频音乐事件会在场地不同位置生成触发点，每个触发点再向外扩散水波式波前；同时叠加中心低频基础抬升、低中频慢波、中频径向流、高频散点尖峰、全局衰减和噪声门共同驱动地形，而不是简单按列频段起伏或只从中心扩散。
5. 地面 DJ 波纹触发器按 Sonic Topography 的方式处理：WebGL 舞台接收实时或离线生成的 `frequencyData`，按低频 Pulse、中高频 Snare 和高频 Spark 三组频段计算正向频谱通量，使用历史均值、标准差、自适应阈值和冷却窗口识别峰值回落；Pulse 触发点分布在中心到中圈，Snare/Spark 分布在中外圈，不再只依赖整体 `beat` 或 `energy` 上升触发。
6. 地面 DJ 柱体对音乐的反应强度参考 Sonic Topography：低频和 kick 对中心、内圈、近中圈有更高高度权重，普通 Pulse 水波承担主要地形抬升，中频负责缓慢流动和方向性起伏，高频只在外圈生成少量尖峰和高光；整体高度、颜色亮度继续保留噪声门和上限，避免整片抬升或整片闪白。
7. 地面 DJ 柱阵使用更密的连续柱体表面，柱体之间不留明显间距；默认相机和舞台位置需要能看到更完整的柱阵范围；圆形柱阵生成时网格覆盖范围必须略大于最终圆形裁剪范围，避免右下角或边缘被方形网格截断。
8. 地面 DJ 需要做成连续声音地形而不是孤立柱阵：主视觉采用圆形/环形声场布局，中心也保留低矮柱体并由低频与整体音量轻微推动，低频、中频和高频分别推动内圈、中圈和外圈的环状起伏；近处和中景柱体保持清晰实体，圆形边界只做轻微收束，远处融合必须由相机视角深度雾化决定，鼠标旋转后变暗、融入背景的柱体区域应随视野距离变化；视野远处需要保留少量深色柱体轮廓，再逐步融入主题背景，避免远景完全消失或出现硬切边；不同沉浸主题需要使用各自的远景雾化色，让柱阵边缘贴合对应背景色温；柱体仍保持不透明，不使用透明度制造消失。
9. 地面 DJ 的默认相机和鼠标拖动旋转中心必须锚定在圆形柱阵整体中心，避免围绕世界原点或画面外偏心点旋转。
10. 重写 shader 中 `uStagePreset` 分支：
   - 星河：星尘旋转、星云呼吸、流星轨迹。
   - DJ：地面 EQ 矩阵和扫描轨迹。
11. WebGL 舞台启用时，底层 Canvas 只保留渐变背景，不再绘制网格、黑色波形、频谱和脉冲前景，避免遮住星河漫游和地面 DJ 主视觉。
12. 检查默认主题和 `animal-island` 主题的预设卡片样式继承。
13. 执行构建和隐私检查。

## 验收标准

- 选择“星河漫游”时才出现最明显的宇宙星河高密粒子。
- “星河漫游”不显示地面 DJ 的柱体。
- “地面 DJ”主视觉由真实柱体地形承载，不显示星尘/轨迹粒子；柱子高度按二维声音地形逻辑平缓起伏，柱体连续排列且能在默认视角中看到更完整的柱阵范围。
- “地面 DJ”柱体整体应像一片圆形声音地貌延展到远处，中心有可见低矮柱体但不过亮，主要能量沿圆环和旋涡路径起伏；近处柱体不应与背景融为一体，默认视野四角不应露出圆盘外背景空缺，圆形边缘不应被方形采样范围截成直线，只有远端地平线自然压低、压暗并融入背景，不出现孤立方阵、硬边终止、中心空洞或透明柱体。
- “地面 DJ”高度、颜色和亮度应随音乐触发点形成的局部波前向外传播：低频/kick 主要在中心到中圈生成有重量的彩色波，中频在中圈生成慢速流动波，高频在外圈生成短促尖锐波；触发点扩散需要有清晰波峰高度、主题色高光和可见的扩散轨迹，但整体亮度受噪声门和上限限制，不应整片闪白。
- “地面 DJ”的水波触发必须优先使用频谱通量峰值：低频 Pulse 使用低频 bin 的正向变化，中高频 Snare/Spark 使用更高频段的正向变化；当实时频谱不可用时才回退到 `MusicEnergyFrame` 的粗粒度能量变化。
- “地面 DJ”的高度响应强度应更接近 Sonic Topography 的权重关系：低频、bass 和 Pulse 波峰明显推动柱体高度，中频形成较宽的流动地形，高频只负责外圈尖峰和局部高光；整体高度不应无限放大，亮度不应超过主题可读范围。
- 默认、动物岛、电影暗场、星河电台、霓虹频谱、暖色舞台和深夜睡眠等主题下，地面 DJ 圆形边缘和远景柱体应分别混入对应主题的深色背景色，不应所有主题使用同一套远景暗色。
- 鼠标旋转视角后，远处变暗和融入背景的柱体应基于当前相机深度重新分布，不应固定在世界坐标的某一侧。
- 鼠标拖动地面 DJ 舞台时，旋转中心应落在柱阵整体中心，不应出现画面绕柱阵旁边的偏心点旋转。
- “地面 DJ”柱体顶面和侧面都使用当前沉浸主题的不透明颜色，亮度不应晃眼，也不应变成黑色或固定霓虹色柱体。
- WebGL 舞台启用时不再出现底层 Canvas 绘制出的网格、整片黑色山体或黑色波形。
- 现有旧设置兼容逻辑不破坏，舞台预设仍能映射旧的视觉模式字段。
- `npm run build` 通过。
- 隐私检查未发现真实密钥、本机歌曲路径或用户配置被写入源码/文档。
