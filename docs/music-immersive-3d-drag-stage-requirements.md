# 沉浸模式 3D 可拖动舞台需求计划

本文档记录音乐沉浸模式新增真 WebGL 3D 可拖动舞台与沉浸窗口拖动禁用规则。该功能只处理界面交互、视觉角度和运行态音乐能量摘要，不保存用户歌曲路径、播放 URL、歌词内容、平台 Cookie、token、音频数据或本机运行历史。

## 背景

- 沉浸模式当前根节点把 `pointerdown` 绑定到窗口拖动入口，但沉浸模式需要把背景拖动留给 3D 舞台，而不是移动窗口。
- WebGL 星辰层已经接入，但此前仍以正交相机和 CSS 3D 包装为主，空间深度、视差和近大远小不够自然。
- Mineradio 的视觉方向强调可交互空间感；本项目可以参考这种交互目标，但不复制其源码、shader、素材或 GPL 实现。

## 目标

1. 明确沉浸模式禁用窗口拖动：沉浸模式下鼠标拖动不移动窗口。
2. 新增沉浸真 3D 舞台：频谱、线条、波纹、主题背景、暗角和歌词统一进入可拖动的 3D 视觉层。
3. 鼠标拖动沉浸背景或歌词区域时旋转 3D 舞台：
   - 横向拖动控制左右旋转。
   - 纵向拖动控制上下倾斜。
   - 松手后有短惯性回弹。
   - 双击背景或歌词区域重置视角。
4. 交互控件保持稳定可用：左侧播放列表、右侧韵律面板、底部控制栏和顶部按钮不跟随 3D 旋转。
5. WebGL 主视觉使用 `PerspectiveCamera`、真实 3D 粒子点云、3D 频谱、3D 波纹和相机轨道拖动；CSS 3D 只保留给歌词轻量浮层。
6. 默认主题、`animal-island` 主题和新增沉浸主题都能继承当前主题色与背景，不出现固定单色或主题割裂。
7. 降低动态模式下减少旋转幅度、关闭明显惯性，避免眩晕。

## 非目标

- 不改在线音乐播放链路、登录态、代理、歌单读取或歌词解析逻辑。
- 不上传、保存或写入原始音频、歌词、歌曲路径、播放链接、Cookie、token 或本机资源路径。
- 不引入 `OrbitControls` 等额外控制器依赖；当前用轻量指针事件驱动自定义相机轨道。
- 不把所有控件做成 3D 可点击面板，避免影响按钮、列表和滑块操作。

## 方案

### 窗口拖动禁用

- 保留普通模式和迷你模式原有窗口拖动。
- 沉浸模式根节点不再调用窗口拖动。
- 沉浸模式顶部标题区、背景区和歌词区的拖动都用于 3D 舞台或被忽略，不移动窗口。

### 3D 舞台

- 新增运行态状态：
  - `immersiveStageYaw`
  - `immersiveStagePitch`
  - `immersiveStageVelocityYaw`
  - `immersiveStageVelocityPitch`
  - `immersiveStageDragging`
- 新增计算样式 `immersiveStageStyle`，通过 CSS 变量把角度、位移和音乐能量传给歌词浮层。
- 将拖动角度同步传入 WebGL 组件，用真实相机轨道和粒子场景响应拖动。
- 新增 `.music-immersive-scene` 和 `.music-immersive-stage`：
  - `scene` 提供 perspective 和拖动命中区域。
  - `stage` 负责歌词、暗角和主题背景的轻量 3D 浮层。
  - WebGL 组件负责主要 3D 星河、频谱、星轨和波纹。

### WebGL 主视觉

- `MusicWebglStarfield` 改为 `PerspectiveCamera`。
- 星空、星云带、频谱、波纹和星轨都进入同一 Three.js `Group`。
- 鼠标拖动改变相机轨道角度，形成真实视差。
- 节拍和低频影响相机 FOV、粒子外扩、波纹半径、光晕亮度和频谱高度。
- WebGL 可用时，Canvas 频谱、线条和波纹切到隐藏；WebGL 不可用时回退 Canvas。

### 交互

- 背景或歌词区域 `pointerdown` 捕获指针并开始旋转。
- `pointermove` 计算角度变化并限制范围。
- `pointerup` 进入惯性衰减动画。
- `dblclick` 重置到默认角度。
- 控件区域继续 `pointerdown.stop`，不会误触 3D 舞台。

## 主题检查

1. 默认主题：旋转时频谱、波纹、暗角和歌词仍清晰，不遮挡底部控制栏。
2. `animal-island` 主题：背景纸感和暖色歌词光晕跟随 3D 舞台，不出现硬切边。
3. 星河、霓虹、暗场、暖场、深夜主题：背景色、歌词色、光晕色继承当前沉浸主题变量。
4. 降低动态：旋转幅度和惯性衰减符合低动态预期。

## 验收标准

- [x] 沉浸模式下窗口拖动被禁用，不会因为拖动背景、歌词或顶部区域移动窗口。
- [x] 沉浸模式背景和歌词区域可拖动 3D 舞台。
- [x] 频谱、线条、波纹、主题背景、暗角和歌词统一跟随 3D 角度变化。
- [x] WebGL 主视觉使用透视相机和真实 3D 粒子空间，不再只是 CSS 平面旋转。
- [x] WebGL 可用时优先使用 3D 频谱、3D 波纹和 3D 星轨；WebGL 不可用时回退 Canvas。
- [x] 左侧播放列表、右侧韵律面板、底部控制栏和按钮仍可正常点击、滚动和拖动进度条。
- [x] 双击背景或歌词区域可以重置 3D 视角。
- [x] 默认主题、`animal-island` 主题和新增沉浸主题下显示正常。
- [x] `npm run build` 通过。
