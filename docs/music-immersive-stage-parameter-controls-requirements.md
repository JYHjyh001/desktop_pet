# 沉浸舞台参数可调需求计划

## 背景

当前沉浸音乐舞台已经保留“星河漫游”和“地面 DJ”两个舞台预设，地面 DJ 参考 Sonic Topography 做了圆形柱阵、频谱通量触发点和水波扩散。后续需要把舞台调参能力放进用户可见面板，让不同歌曲、主题和视角下可以调整舞台密度、运动幅度和触发反应，而不是继续依赖固定常量。

参考方向：

- Sonic Topography：地面 EQ 提供 `motionSpeed`、`amplitude`、`terrainDensity`，触发器提供 sensitivity、cooldown、pulseStrength，音乐峰值触发点会在地形上扩散。
- Mineradio：舞台控制面板强调直接可调、即时反馈和预设化参数，不把用户暴露在过多开发者细节里。

## 目标

- 在沉浸式韵律面板中新增“舞台参数”控制区。
- 参数修改立即影响 WebGL 舞台，不需要重新进入沉浸模式。
- 参数保存到本机设置，只保存数值，不写入歌曲路径、播放列表或其他用户隐私数据。
- 地面 DJ 的柱子密度、高度、运动响应、触发扩散、视距都可以调整。
- 星河漫游保留原粒子舞台，不引入地面 DJ 柱体；通用强度和视距控制不破坏现有视觉身份。
- 默认主题和 `animal-island` 主题下控件都能继承或匹配现有沉浸式样式。

## 参数设计

首版采用压缩后的用户参数，避免直接暴露 Sonic Topography 的全部高级项：

- 高度：映射 Sonic Topography 的 `amplitude`，控制柱体高度上限和音乐反应幅度。
- 响应：映射 `motionSpeed`，控制柱体追随音乐变化的平滑速度。
- 密度：映射 `terrainDensity`，控制地面 DJ 柱阵网格数量。
- 波峰：控制触发点扩散后的水波抬升和高光强度。
- 触发：映射触发器 sensitivity 和 pulseStrength，控制音乐峰值生成扩散点的频率和强度。
- 视距：参考舞台控制面板中的镜头调节，控制默认轨道镜头距离。

## 实现范围

1. 类型与默认值
   - 新增 `MusicStageTuning` 类型。
   - 新增默认参数对象，所有字段使用安全范围归一化。

2. 设置持久化
   - 在音乐窗口本机设置中保存 `visualStageTuning`。
   - 读取旧设置时缺失字段自动回退默认值。
   - 参数对象变化时触发保存。

3. 控制面板
   - 在沉浸韵律面板加入舞台参数滑杆。
   - 显示百分比读数和一键重置。
   - 保持控制区紧凑，避免遮挡歌词和播放列表。

4. WebGL 舞台
   - 地面 DJ 密度变化时重建 `InstancedMesh` 柱阵。
   - 高度影响最大柱高和整体音乐抬升。
   - 响应影响柱体平滑跟随速度。
   - 波峰影响扩散波的高度、亮度和衰减范围。
   - 触发影响频谱通量峰值触发点的敏感度、强度和冷却。
   - 视距影响默认轨道相机距离，鼠标旋转中心继续锚定柱阵中心。

## 验收标准

- 沉浸式面板出现“舞台参数”区域，包含高度、响应、密度、波峰、触发、视距和重置。
- 修改密度后，地面 DJ 柱阵数量发生变化且不会出现方形边缘空缺。
- 修改高度和波峰后，柱体起伏与触发扩散可明显变强或变弱。
- 修改响应后，柱体运动从更平滑到更迅速可辨认。
- 修改触发后，音乐峰值触发点数量和强度变化合理，不出现持续爆闪。
- 修改视距后，地面 DJ 默认视野远近变化合理，鼠标旋转中心仍在柱阵整体中心。
- 星河漫游不出现地面 DJ 柱体。
- 默认主题和 `animal-island` 主题下控制面板文字、按钮、滑杆可读。
- 本次改动不把歌曲路径、平台凭据、播放 URL、API Key 或用户本机配置写入源码或文档。

## 后续可选增强

- 增加舞台参数预设导入导出，但导出内容只能包含舞台视觉参数。
- 增加高级触发器面板，分别调 Pulse、Snare 和 Spark。
- 增加不同主题下的自动参数建议。

## 二期：星河漫游参数与更大调节范围

### 背景

首版舞台参数主要服务地面 DJ，星河漫游只有全局强度、降低动态和视距会受到影响。后续需要让星河漫游也拥有符合自身视觉身份的参数，同时扩大地面 DJ 的可调范围，便于用户在低性能、柔和、夸张和演出效果之间调节。

### 目标

- 舞台参数按当前舞台分别保存，星河漫游和地面 DJ 切换后不互相污染。
- 星河漫游显示独立参数文案：星量、流速、纵深、层高、星云、闪耀、视距。
- 地面 DJ 保留柱阵文案：高度、响应、密度、波峰、触发、视距。
- 两个舞台的参数范围都扩大，但仍做安全裁剪，避免直接把舞台推到不可见或性能极端状态。
- 星河漫游的星量变化会重建粒子几何，其他参数即时作用于 shader 和镜头。
- 地面 DJ 的密度范围扩大后继续只重建柱阵，其他参数即时生效。

### 星河漫游参数映射

- 星量：控制星尘、星云和流星粒子数量。
- 流速：控制星尘旋转、星云臂流动和流星轨迹速度。
- 纵深：控制星河前后空间尺度、旋臂展开和镜头内空间压缩感。
- 层高：控制星尘、星云团和流星轨迹在上下方向的铺开范围。
- 星云：控制星云臂抬升、柔光透明度和旋臂可见度。
- 闪耀：控制星点闪烁、节拍高光和流星反应强度。
- 视距：控制默认镜头距离。

### 地面 DJ 范围调整

- 高度、响应、密度、波峰、触发和视距的范围扩大。
- 密度上限扩大时需要限制 WebGL 实例数，保持可用性能。
- 触发和波峰允许更强，但继续通过自适应阈值、冷却和亮度裁剪避免持续爆闪。

### 验收标准

- 在星河漫游下，舞台参数显示为星量、流速、纵深、层高、星云、闪耀、视距。
- 在地面 DJ 下，舞台参数显示为高度、响应、密度、波峰、触发、视距。
- 两个舞台参数独立保存，切换舞台后保留各自上次的数值。
- 星量调高后粒子数量明显增加，调低后星河更稀疏。
- 流速、纵深、星云、闪耀调整后星河漫游有可辨认变化。
- 层高调低后星河更扁，调高后上下分布更厚，且不影响地面 DJ。
- 地面 DJ 参数范围比首版更大，且密度上限不会导致构建失败。
- 默认主题和 `animal-island` 主题下参数控件仍可读。
- 不新增歌曲路径、播放 URL、歌词内容、平台 Cookie、token、音频数据或本机运行历史持久化。
