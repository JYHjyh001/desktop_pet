# 星河内歌词与卡片舞台化需求计划

本文档记录沉浸音乐模式的星河空间融合增强。本功能只调整前端运行态视觉，不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 背景

当前星河漫游的 WebGL 舞台与歌词、播放列表、韵律面板仍有明显层级分离：星河在 Canvas 中，歌词和卡片是 DOM 浮层。用户希望接近 Mineradio 的观感，让歌词和歌曲卡片像处在星河空间中，而不是盖在星河上面。

Mineradio 采用 GPL-3.0，且声明界面视觉设计与原创视觉表达归作者所有。本项目只参考高层设计方法，自研实现，不复制第三方代码、资源、参数表或原始视觉表达。

## 目标

1. 星河漫游下，歌词附近不再单独生成局部粒子点云；空间感由全局 WebGL 星河、镜头透视和 DOM 舞台层次共同表达。
2. 歌词 DOM 层继续负责可读文字和逐字进度，当前句仍然即时切换，不增加入场/退场动画或强制重建。
3. 沉浸播放列表、韵律面板、舞台预设卡片和列表行改成更轻的透明玻璃舞台质感，弱化“实心面板盖在星河上”的感觉。
4. 默认主题与 `animal-island` 主题都要保持卡片、按钮、列表、空状态和错误提示可读。
5. 当前歌词文本只允许作为运行态 WebGL 纹理输入，不允许用于生成局部粒子点云，也不新增持久化字段。

## 非目标

1. 不把完整歌词文本、歌曲路径、播放 URL 或平台凭据写入源码、文档示例或本机以外位置。
2. 不复制 Mineradio 的 Three.js 歌词 mesh、shader、纹理生成、3D 歌单架代码或视觉参数。
3. 不重写播放、歌词解析、在线歌词读取或逐字进度同步链路。
4. 不在本阶段实现完整 3D 歌单架；本阶段先优化沉浸模式已有播放列表和韵律面板的星河融合感。

## 实现步骤

1. 阅读 `docs/RELEASE_PRIVACY_CHECKLIST.md`，确认隐私边界。
2. 在 `MusicWindow.vue` 中避免为局部粒子效果继续计算或传递当前歌词摘要；后续 WebGL 3D 歌词只允许把歌词作为临时纹理输入。
3. 在 `MusicWebglStarfield.vue` 中移除自研 `lyricRiver` WebGL 粒子层，避免星河漫游时围绕当前歌词形成细小光点星云。
4. 保留沉浸歌词 DOM 舞台样式，让主歌词依靠透明文字、投影、进度光和全局星河背景形成空间层次。
5. 调整沉浸播放列表、韵律面板、舞台卡片和列表行的玻璃质感，并补齐 `animal-island` 主题覆盖。
6. 运行构建、检查默认主题和 `animal-island` 主题样式继承、执行隐私关键词扫描。
7. 完成后从未完成记录移入完成记录。
