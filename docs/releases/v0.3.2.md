# PetDrawer v0.3.2

## 更新内容

1. 重写 GitHub README，新增中英文入口、功能亮点、功能矩阵、隐私边界、下载使用、开发运行、技术栈和文档索引。
2. 整理开发文档，将已完成能力、未完成能力和后续实施计划按模块合并，减少同类事项重复记录。
3. 新增项目代码扫描与优化记录，记录构建检查、隐私扫描、无用代码清理、构建体积和后续技术债。
4. 清理前端未使用符号，移除未引用的音乐推荐选项、视觉标签计算属性、图片选择函数、音乐意图构造函数和 WebGL 中心波清理函数。
5. 将沉浸 WebGL 星河组件改为异步加载，降低普通音乐窗口主包体积；Three.js 仍作为独立沉浸视觉依赖加载。
6. 统一开发端口为 `127.0.0.1:1421`，同步 Vite、Tauri 和项目注意事项中的说明。
7. 新增沉浸模式顶部音乐搜索和本机壁纸导入能力，包含多平台聚合搜索、隐藏式搜索入口、图片/视频壁纸、强度和柔化调节。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词、聊天配置和 Bridge Token 只保存在用户本机 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、音乐路径、导入歌曲、宠物素材、使用历史和本机资源目录只保存在用户本机应用数据目录。
3. 音乐 metadata 标签读取只在本机进行，不上传原始音频、音频指纹、歌曲路径或识别服务密钥。
4. 网易云和酷狗平台凭据、Cookie、token、设备标识、播放 URL、搜索结果和歌单读取状态只按功能需要保存在本机配置或运行态，不写入源码、文档示例或 Release 附件。
5. 沉浸模式壁纸只保存用户选择的本机路径和视觉参数，不复制、上传或打包用户图片/视频。
6. Codex 任务内容、终端输出、项目路径和用户会话内容不写入源码、Release notes 或 Release 附件。
7. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json`、音乐文件、宠物素材导入目录或其他本机私密配置。
