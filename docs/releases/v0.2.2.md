# PetDrawer v0.2.2

## 更新内容

1. 宠物记忆系统升级为 SQLite + FTS5，本地记忆主文件改为 `pet-memory.db`。
2. 首次升级时会自动读取旧版 `pet-memory.json`，在数据库为空时迁移最近聊天记录和长期记忆。
3. 记忆检索优先使用 SQLite FTS5 全文搜索，并在无结果或查询不可用时回退到本地关键词打分。
4. 记忆导入、导出和打开目录功能继续可用；导出文件仍为 JSON，便于用户自己备份和迁移。
5. 更新 `.gitignore` 和发布隐私清单，额外忽略 `pet-memory.db`、`pet-memory.db-*` 和记忆数据库备份。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词等配置只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史和导入资源只保存在用户本机应用数据目录。
3. 宠物聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.db`；旧版 `pet-memory.json` 只用于首次迁移。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。
5. 记忆导出 JSON 可能包含私人聊天、偏好、项目和事件信息，只适合用户自己备份或迁移。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.2_x64-setup.exe
```
