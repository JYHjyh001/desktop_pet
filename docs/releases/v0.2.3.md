# PetDrawer v0.2.3

## 更新内容

1. 修复开机自启路径残留问题，保存设置时会重新同步 Windows Run 注册表中的 `PetDrawer` 启动项。
2. 修复开发模式下误写 `target\debug\pet_drawer.exe` 的问题；开发版运行时会把自启目标解析为同项目的 `target\release\pet_drawer.exe`。
3. 修复升级或切换运行目录后设置页误判自启状态的问题；现在会校验注册表路径是否匹配预期启动 exe。
4. 关闭开机自启时会清理已有的 `PetDrawer` 启动项，包括旧版本或旧路径残留。

## 隐私说明

1. 本次修改只调整 Windows 开机自启注册表目标路径，不收集、不上传用户配置或本机路径。
2. 用户 AI API Key、Base URL、模型、系统提示词等配置只保存在用户本机应用数据目录的 `config.json`。
3. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史和导入资源只保存在用户本机应用数据目录。
4. 宠物聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.db`；旧版 `pet-memory.json` 只用于首次迁移。
5. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.3_x64-setup.exe
```
