# PetDrawer v0.2.10

## 更新内容

1. 新增微信 ClawBot 通用 HTTP 接入桥，允许 OpenClaw 或其他服务通过 `POST /clawbot/chat` 调用 PetDrawer 当前 AI 聊天能力。
2. HTTP 接入桥支持自定义监听地址、端口、路径和可选 Bridge Token。
3. 接入桥复用 PetDrawer 当前伴侣、AI 配置、聊天上下文和记忆处理逻辑，返回统一 JSON 响应。
4. 设置页“微信”新增“通用 HTTP 接入”配置区，README 补充本机、虚拟机和服务器反向隧道接入示例。
5. 本地 OpenClaw 启动脚本模式加入忽略规则，避免误提交包含本机路径或私有服务信息的脚本。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词和 ClawBot HTTP Bridge Token 只保存在用户本机 `config.json`。
2. HTTP 接入桥默认只监听 `127.0.0.1`，不主动暴露到公网；跨机器使用时应通过 SSH 隧道或内网反向代理，并配置 Token。
3. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json`、微信账号、目标会话或本机 OpenClaw 脚本。
4. 使用 ClawBot 调用 PetDrawer AI 时，用户应自行确认微信消息内容和返回内容是否适合转发。

## 安装包

```txt
PetDrawer_0.2.10_x64-setup.exe
```
