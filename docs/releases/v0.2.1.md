# PetDrawer v0.2.1

## 更新内容

1. 设置页新增“系统”分区，可控制是否开机自启，以及是否根据最近打开频率自动加入“常用”。
2. AI 接口设置新增“测试连接”，可用当前表单里的服务商、Base URL、模型和 API Key 发起一次短请求。
3. 宠物对话新增本地记忆系统，会保存最近聊天记录，并把重要偏好、项目、事件和用户画像提取为长期记忆。
4. 记忆设置页支持查看、删除、清空、导入、导出长期记忆，并可直接打开记忆文件目录。
5. 增强本地隐私忽略规则，避免 `pet-memory.json`、记忆导出文件和本机数据目录被误提交。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词等配置只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史和导入资源只保存在用户本机应用数据目录。
3. 宠物聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.json`。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json` 或其他本机私密配置。
5. 记忆导出 JSON 可能包含私人聊天、偏好、项目和事件信息，只适合用户自己备份或迁移。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.1_x64-setup.exe
```
