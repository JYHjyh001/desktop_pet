# PetDrawer v0.2.5

## 更新内容

1. 新增界面主题切换，在原有默认样式之外提供内置“动物岛”暖色主题，并同步作用于抽屉、聊天窗口和右键菜单。
2. 宠物聊天回复新增打字机式逐字显示，长回复自动加速完成，并可在外观设置中改为立即完整显示。
3. 修复逐字回复可能停留在首个字符或词语、仅在继续输入时才刷新完整内容的问题。
4. 本机导入的宠物形象支持编辑名称和替换各状态动画，也可移除可选动画并回退到待机状态。

## 隐私说明

1. 用户界面主题、聊天展示偏好、AI API Key、Base URL、模型、系统提示词及配置标签只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史、导入及编辑后的宠物素材只保存在用户本机应用数据目录。
3. 宠物聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.db`；旧版 `pet-memory.json` 只用于首次迁移。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.5_x64-setup.exe
```
