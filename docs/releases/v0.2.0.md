# PetDrawer v0.2.0

## 更新内容

1. 新增宠物右键“对话”入口，打开独立宠物聊天窗口。
2. 新增 AI 接口设置，支持 OpenAI 兼容、DeepSeek、Anthropic、Gemini、Ollama 和自定义服务。
3. 新增软件、文件夹、网站三类快捷入口，统一通过“添加”按钮创建。
4. 文件夹和网站支持默认图标，并适配缩略/详细显示。
5. 缩略/详细显示切换移动到抽屉右上角“设置”按钮旁边。
6. 设置弹窗按入口管理、AI 接口、窗口、更新、诊断分类。
7. 软件卡片内支持单独勾选是否管理员启动。
8. 增加发布隐私清单和本地数据忽略规则，防止用户本机配置被提交。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词等配置只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口和打开历史只保存在用户本机应用数据目录的 `apps.json`。
3. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json` 或其他本机私密配置。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.0_x64-setup.exe
```
