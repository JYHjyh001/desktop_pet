# PetDrawer v0.2.9

## 更新内容

1. 抽屉入口类型筛选改为组合筛选，可同时选择软件、文件夹、文件和网站。
2. 新增文件快捷入口，支持选择本机文件、用系统默认程序打开文件，并在详细卡片中打开文件所在目录。
3. 新增微信 ClawBot 设置页，可通过 OpenClaw 官方 `openclaw-weixin` 通道发送测试消息，并按配置同步宠物聊天中的用户消息或宠物回复。
4. 新增文件入口默认图标，并适配默认主题和“动物岛”主题。
5. README 补充文件入口和微信 ClawBot 接入步骤。

## 隐私说明

1. 用户的软件、文件夹、文件和网站入口路径只保存在用户本机应用数据目录或用户自定义的本机数据目录。
2. 微信 ClawBot 的 OpenClaw 命令、通道、账号、目标会话和同步开关只保存在用户本机 `config.json`。
3. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json`、微信账号或目标会话。
4. 使用 ClawBot 同步到微信时，用户应自行确认目标会话和消息内容是否适合发送。

## 安装包

```txt
PetDrawer_0.2.9_x64-setup.exe
```
