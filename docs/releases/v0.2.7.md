# PetDrawer v0.2.7

## 更新内容

1. 新增短期记忆压缩摘要：默认保留最近 10 轮原文对话，更早对话达到触发阈值后会滚动压缩为一条特殊摘要记忆，和长期记忆一起参与后续回复。
2. 新增伴侣好感度系统：每位伴侣独立保存好感度、关系阶段、心情、信任度、亲密度和变化日志，支持在聊天窗口中查看、手动调整、重置或开关。
3. 优化聊天显示：支持本地 Twemoji 表情渲染、表情选择器、AI 主动表情频率设置、旁白显示开关和聊天窗口内的对话显示设置。
4. 优化 DeepSeek 聊天输出：优先使用 JSON Output 获取回复、情绪和候选表情，异常或空内容时自动降级为普通聊天重试。
5. 设置页新增“关于”分类展示内置表情资源许可，并补充短期记忆摘要相关设置项。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词、连接配置标签和短期记忆摘要设置只保存在用户本机应用数据目录的 `config.json`。
2. 用户的软件、文件夹、网站入口、使用历史和导入的本地资源只保存在用户本机应用数据目录。
3. 各伴侣的聊天记录、长期记忆、短期摘要、好感度状态和关系变化日志只保存在用户本机应用数据目录的 `pet-memory.db`。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。
5. 记忆导出 JSON 可能包含私人聊天、偏好、关系和事件信息，只适合用户自己备份或迁移。
