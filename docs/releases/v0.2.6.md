# PetDrawer v0.2.6

## 更新内容

1. 新增多伴侣档案管理，可为不同角色保存名称、人设、关系状态、绑定形象、语音标识、附加规则与可选模型覆盖，并在设置中快速切换。
2. 聊天记录与长期记忆按伴侣 ID 隔离存储和检索，切换伴侣时不会混用历史对话或记忆；旧版 JSON 记忆首次迁移至默认伴侣。
3. 强化记忆管理流程，支持针对当前伴侣查看、导入、导出、清理长期记忆，以及单独清空聊天记录。
4. 整理 AI 连接配置标签和设置界面布局，连接配置以下拉方式切换，并完善“动物岛”主题下的伴侣与聊天界面表现。

## 隐私说明

1. 伴侣档案、当前伴侣标识、模型覆盖、AI API Key、Base URL、全局回复规则和连接配置标签只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史和导入的宠物素材只保存在用户本机应用数据目录。
3. 各伴侣的聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.db`；旧版 `pet-memory.json` 只用于首次迁移。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.6_x64-setup.exe
```
