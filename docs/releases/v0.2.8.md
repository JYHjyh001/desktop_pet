# PetDrawer v0.2.8

## 更新内容

1. 新增故事模式窗口，可从快捷入口抽屉进入，并支持本机故事存档的创建、继续、重命名和删除。
2. 伴侣档案扩展为更完整的角色卡字段，支持人格摘要、场景、首条消息、示例对话、作者备注和后置指令，并支持角色卡 JSON 导入导出。
3. 新增数据存储目录设置，可分别配置基础数据、记忆、宠物素材和图标目录，并在保存时迁移本机应用数据。
4. 宠物形象支持导入 `webm`、`mp4` 等动画素材，预览区和桌面宠物窗口可播放视频动画。
5. 新增宠物尺寸设置，保存后会同步调整桌面宠物窗口大小。
6. 改进配置写入和损坏配置恢复逻辑，降低异常退出时本机配置损坏风险。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词、连接配置标签、伴侣角色卡字段和窗口设置只保存在用户本机应用数据目录的 `config.json`。
2. 用户的软件、文件夹、网站入口、使用历史、导入图标、宠物素材和故事存档只保存在用户本机应用数据目录或用户自定义的本机存储目录。
3. 各伴侣的聊天记录、长期记忆、短期摘要、好感度状态和关系变化日志只保存在用户本机应用数据目录或用户自定义的本机记忆目录。
4. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json` 或其他本机私密配置。
5. 角色卡、记忆导出 JSON 和故事存档可能包含私人设定、聊天内容、偏好和事件信息，只适合用户自己备份或迁移。
