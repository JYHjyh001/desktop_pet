# PetDrawer v0.2.4

## 更新内容

1. AI 接口支持保存和切换多组本机配置标签，可管理服务商、Base URL、模型和 API Key，同时保持原有活动连接配置兼容。
2. 宠物记忆增强为陪伴型长期记忆提取，支持称呼、偏好、边界、习惯、目标、关系与重要经历等类型，并在保存前跳过疑似敏感信息。
3. 记忆设置页支持手动新增、编辑、永久删除、清空长期记忆及清空短期聊天记录；删除相关操作使用明确确认提示。
4. 聊天中支持明确的长期记忆删除指令，并收紧指令识别，避免否定句或讨论内容误触发物理删除。
5. 增加 AI 配置标签、记忆导入导出、删除本地资源及管理员启动等重要操作的提示与确认流程。
6. 修正开机自启状态识别，在当前运行路径与注册表启动路径一致时正确显示为已启用。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词及配置标签只保存在用户本机应用数据目录的 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、网站入口、打开历史和导入资源只保存在用户本机应用数据目录。
3. 宠物聊天记录和长期记忆只保存在用户本机应用数据目录的 `pet-memory.db`；旧版 `pet-memory.json` 只用于首次迁移。
4. 长期记忆写入会跳过疑似密码、Token、银行卡号、身份证号、精确住址和联系方式等敏感内容。
5. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db` 或其他本机私密配置。

## 安装包

本版本 Windows 安装包命名约定：

```txt
PetDrawer_0.2.4_x64-setup.exe
```
