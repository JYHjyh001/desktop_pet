# PetDrawer v0.3.1

## 更新内容

1. 新增沉浸式音乐模式，支持全屏可视化、歌词显示、播放控制和沉浸面板。
2. 新增网易云音乐登录、歌单读取、在线歌词和临时在线播放能力。
3. 增强沉浸模式歌词同步，支持在线 YRC 逐字歌词、普通 LRC 回退和歌词偏移调整。
4. 增强音乐可视化，支持实时频谱、节拍图预分析和 WebView 不支持多路音频分析时的安全视觉回退。
5. 新增沉浸模式左侧播放列表，支持本地音乐和当前网易云歌单切换，并可独立隐藏播放列表和韵律面板。
6. 增强 `animal-island` 主题和窗口动效，补齐音乐面板、弹窗、气泡和多个窗口的主题表现。
7. 补充音乐沉浸模式、网易云音乐、主题刷新和后续开发计划相关需求文档。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词、聊天配置和 Bridge Token 只保存在用户本机 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、音乐路径、导入歌曲、宠物素材、使用历史和本机资源目录只保存在用户本机应用数据目录。
3. 音乐 metadata 标签读取只在本机进行，不上传原始音频、音频指纹、歌曲路径或识别服务密钥。
4. 网易云登录凭据、Cookie、账号资料和歌单读取状态只保存在用户本机应用数据目录，不写入源码、文档示例或 Release 附件。
5. Codex 任务内容、终端输出、项目路径和用户会话内容不写入源码、Release notes 或 Release 附件。
6. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json`、音乐文件、宠物素材导入目录或其他本机私密配置。
