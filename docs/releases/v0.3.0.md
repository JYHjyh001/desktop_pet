# PetDrawer v0.3.0

## 更新内容

1. 新增 Codex App Server 集成，支持任务状态汇总、最近任务列表和宠物动作联动。
2. 宠物 Codex 状态提示改为独立气泡窗口，支持宠物缩放后的边界避让，并适配默认主题和 `animal-island` 主题。
3. 取消 Codex 状态主动气泡提醒，保留鼠标悬浮宠物时查看状态；全部任务完成后保持完成动画，直到用户悬浮确认。
4. 多个 Codex 任务完成时，在宠物右下角显示轻量完成数量角标，避免和悬浮气泡重叠。
5. 新增音乐窗口与本机音乐管理能力，支持歌曲列表、分类、播放列表和本机资源存储配置。
6. 增强宠物素材配置，支持更多宠物动画状态、导入校验和主题界面适配。
7. 增强 AI 聊天和记忆相关处理，补充需求文档、已完成功能记录和未完成功能记录。
8. 增强 Windows exe 图标提取流程与文档说明。

## 隐私说明

1. 用户 AI API Key、Base URL、模型、系统提示词、聊天配置和 Bridge Token 只保存在用户本机 `config.json`。
2. 用户快捷入口、软件路径、文件夹路径、音乐路径、导入歌曲、宠物素材、使用历史和本机资源目录只保存在用户本机应用数据目录。
3. 音乐 metadata 标签读取只在本机进行，不上传原始音频、音频指纹、歌曲路径或识别服务密钥。
4. Codex 任务内容、终端输出、项目路径和用户会话内容不写入源码、Release notes 或 Release 附件。
5. 仓库和 Release 附件不包含用户 API Key、token、`.env`、`config.json`、`apps.json`、`pet-memory.json`、`pet-memory.db`、`story-saves.json`、音乐文件、宠物素材导入目录或其他本机私密配置。
