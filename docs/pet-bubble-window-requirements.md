# 宠物气泡独立窗口需求计划

## 背景

宠物窗口大小可调后，原本绘制在宠物窗口内部的 Codex 状态气泡和未读徽标会受到宠物窗口尺寸限制，可能出现位置不美观、被裁剪或无法完整显示的问题。

## 目标

1. 新增独立透明窗口承载宠物状态气泡。
2. 气泡窗口根据宠物窗口的实际位置和大小动态定位。
3. 气泡优先显示在宠物上方，空间不足时自动切换到下方。
4. 气泡窗口在屏幕边界内 clamp，避免超出显示器可视区域。
5. 气泡箭头根据宠物中心动态偏移，窗口被边界推开后仍指向宠物。
6. Codex 未读徽标也使用独立窗口显示，避免继续占用宠物窗口内部空间。
7. 默认主题和 `animal-island` 主题都要保持清晰可读。

## 非目标

1. 不改变 Codex 状态聚合逻辑。
2. 不新增 Codex 状态持久化。
3. 不保存 Codex 对话正文、项目路径、终端输出或本机日志路径。
4. 不改变宠物大小设置的存储方式。
5. 不新增声音提醒或复杂重复提醒策略。

## 功能方案

### 窗口

新增 Tauri 窗口：

- label：`pet-bubble`
- 透明、无边框、无阴影、不可调整大小
- 默认隐藏
- 跟随宠物置顶设置
- 不进入任务栏

### 定位

后端根据以下信息计算气泡窗口位置：

1. 宠物窗口外部位置。
2. 宠物窗口外部大小。
3. 气泡窗口目标大小。
4. 当前显示器可视区域。

定位规则：

1. 普通气泡优先放在宠物上方居中。
2. 上方空间不足时放到宠物下方。
3. 横向位置限制在显示器左右边界内。
4. 纵向位置限制在显示器上下边界内。
5. 箭头位置使用宠物中心相对气泡窗口的偏移计算。

### 前端

1. `PetWindow` 继续监听 Codex 状态事件并维护气泡显示时长。
2. `PetWindow` 不再直接渲染气泡 DOM，而是调用后端命令显示、隐藏或重新定位 `pet-bubble` 窗口。
3. 新增 `PetBubbleWindow` 组件负责渲染气泡和徽标。
4. 用户点击气泡或徽标时确认 Codex 未读提醒，并隐藏气泡窗口。
5. 宠物拖动时持续重新定位气泡窗口。

## 主题要求

1. 默认主题复用现有 Codex 气泡状态色。
2. `animal-island` 主题需要对 `pet-bubble` 独立窗口补充选择器，不能只依赖 `.pet-window` 父级。
3. 气泡文本最多两行，徽标单行省略，避免窗口内容溢出。

## 隐私要求

1. 气泡窗口只接收脱敏后的状态短文案和状态类型。
2. 不写入用户 Codex 会话内容、项目路径、API Key、token 或本机配置。
3. 文档示例只使用通用说明，不包含真实用户路径。

## 验收标准

1. 宠物窗口调到最小和最大尺寸时，气泡不被宠物窗口裁剪。
2. 宠物靠近屏幕顶部时，气泡自动显示到宠物下方。
3. 宠物靠近屏幕左右边缘时，气泡窗口保持在屏幕内。
4. 气泡箭头在边界避让后仍指向宠物中心附近。
5. 点击气泡或徽标可以确认 Codex 未读提醒。
6. 默认主题和 `animal-island` 主题下气泡、徽标、错误态和完成态都清晰可读。
7. `npm run build` 通过。
8. 提交前隐私检查未发现真实密钥、本机配置或用户隐私数据进入仓库。
