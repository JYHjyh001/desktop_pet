# 在线音乐不可播放自动跳过需求

本文档记录网易云音乐和酷狗音乐歌单中存在下架、无版权、会员、地区限制或平台未返回播放链接时的播放器容错方案。本功能只处理运行态播放状态，不保存用户歌曲路径、播放 URL、Cookie、token、平台凭据、歌词文本或本机资源路径。

## 背景

平台歌单可能仍保留某首歌的摘要，但该歌曲已经下架、无版权、需要会员或受地区限制。此时接口可能无法返回播放地址，或返回的临时播放链路无法继续读取。播放器不应因为一首歌不可播而卡住整个歌单。

## 目标

- 播放地址获取失败时，识别明确的不可播放原因。
- 在当前运行态标记不可播放歌曲，并在列表中显示原因。
- 自动连续播放时，跳过已知不可播放歌曲并继续尝试后续歌曲。
- 手动点击不可播放歌曲时允许重试，而不是永久禁用。
- 预取逻辑跳过已知不可播放歌曲，减少无效请求。

## 非目标

- 不绕过平台会员、版权、地区、DRM 或付费限制。
- 不把平台临时播放 URL、Cookie、token 或设备标识写入本地音乐库。
- 不在读取歌单时批量探测每首歌是否可播放，避免大量请求和平台限制。
- 不自动把其他平台搜索结果当作同一首歌替换播放。

## 实现方案

1. 前端运行态维护不可播放状态缓存。
   - 网易云按歌曲 ID 记录。
   - 酷狗按歌曲 hash 记录。
   - 状态包含原因、失败时间和重试时间。
2. 播放失败分类。
   - 仅将“暂无版权、资源不可用、需要会员、地区限制、播放链接为空、试听片段、未拿到完整播放授权”等明确原因标记为不可播放。
   - 普通网络异常不长期标记。
3. 连续播放容错。
   - 下一首候选会扫描后续歌曲。
   - 已知不可播放歌曲直接跳过。
   - 自动切歌遇到新的不可播放错误时继续尝试后续歌曲。
4. UI 状态。
   - 普通平台列表显示“不可播放：原因”。
   - 沉浸播放列表显示“不可播”，悬浮可查看原因。
   - 播放按钮在不可播放状态下显示“重试”。

## 隐私边界

- 不新增本地持久化。
- 不写入用户歌曲路径、平台播放 URL、Cookie、token、歌词文本或音频数据。
- 不上传音频或歌词数据。
- 不改变平台凭据的本机保存规则。

## 验收标准

- 平台播放地址明确不可用时，歌曲行显示不可播放原因。
- 自动播放到不可播放歌曲时不会卡住队列，会继续尝试下一首可播歌曲。
- 手动点击不可播放歌曲可以重新请求播放地址。
- 预取不会反复请求当前运行态已知不可播放歌曲。
- 默认主题和 `animal-island` 主题下不可播放状态都有可识别样式。
