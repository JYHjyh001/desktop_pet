# WebGL 3D 歌词舞台需求计划

本文档记录沉浸音乐模式中把星河漫游歌词从可见 DOM 浮层改为 WebGL 3D 舞台对象的实现计划。本功能只使用当前运行态歌词文本、同步进度和视觉参数生成临时 GPU 纹理，不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 背景

当前星河漫游歌词仍由 DOM 文本层显示，虽然有 CSS 透视、光晕和投影，但不会进入 WebGL 深度缓冲，也无法与星河粒子形成真实前后遮挡。用户希望歌词像 Mineradio 那样处在星河空间中，而不是盖在星河上方。

Mineradio 采用 GPL-3.0，且其界面视觉设计与原创视觉表达归作者所有。本项目只参考“歌词舞台与粒子舞台同步工作”的高层设计思路，自研 WebGL 纹理、材质、参数和布局，不复制第三方代码、资源、纹理或视觉参数。

## 目标

1. 星河漫游下，当前歌词、上一句和下一句由 `MusicWebglStarfield.vue` 内的 WebGL 平面显示，参与同一 Three.js 场景和相机；星河自动运动由粒子 shader 自身流动承担，不通过旋转整个舞台组实现。
2. 当前歌词使用 CanvasTexture 生成可读纹理，包含同步进度高亮、描边、阴影和柔光；不在歌词附近额外生成粒子点云。
3. 歌词本体必须稳定可见，不再依赖透明粒子场里的深度写入；空间感通过 WebGL 柔雾、反射、前景空气遮罩和星河主体层共同形成。
4. DOM 歌词只作为 WebGL 未启用、WebGL 不可用、地面 DJ 和无当前歌曲时的回退；星河 WebGL 接管后，加载、空态和错误由 WebGL 文字平面绘制，长间隔间奏不生成主歌词占位文字，避免任何 DOM 层歌词或状态胶囊叠在星河上。
5. 默认主题与 `animal-island` 主题下歌词、状态、空态和错误态仍可读。

## 非目标

1. 不复制 Mineradio 的歌词 mesh、shader、纹理生成、3D 歌单架或原始视觉参数。
2. 不改歌词解析、逐字进度计算、在线歌词读取或播放同步链路。
3. 不持久化当前歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。
4. 不把歌曲卡片重做成完整 3D 歌单架，本阶段只处理星河漫游歌词进入 WebGL。

## 实现步骤

1. 阅读 `docs/RELEASE_PRIVACY_CHECKLIST.md`，确认隐私边界。
2. 在 `MusicWindow.vue` 中生成只用于渲染的运行态歌词状态，传递当前句、上下句、同步进度、状态、字体比例、位置、远近、弱化和光晕等视觉参数。
3. 在 `MusicWebglStarfield.vue` 中新增 WebGL 歌词舞台对象：主歌词纹理平面、上一句/下一句弱化纹理平面、柔光背景平面和地面反射平面。
4. WebGL 歌词只在星河漫游且 WebGL 可用时显示；地面 DJ、WebGL 不可用和无当前歌曲时继续使用 DOM 回退。
5. 调整 `MusicWindow.vue` 和 `styles.css`，星河 WebGL 歌词启用时取消 DOM 歌词 section 渲染，加载、空态和错误统一进入 WebGL 状态文字；长间隔间奏继续显示真实歌词行，不生成“间奏”占位；补齐 `animal-island` 主题继承。
6. 运行构建、默认主题与 `animal-island` 主题静态检查、隐私关键词扫描和 `git diff --check`。

## 验收标准

- [x] 星河漫游下当前歌词由 WebGL 显示，DOM 不再作为可见主歌词叠在上层。
- [x] 当前歌词切换仍即时同步，不增加入场/退场动画、强制 key 重建或延迟层。
- [x] 当前歌词与星河粒子处于同一 Three.js 场景，文字像在星河之间；文字本体保持稳定可见，空间层次由星河主体、柔雾、前景空气遮罩和反射共同承担；星河自动运动只走粒子 shader，不旋转承载歌词参照空间的舞台组。
- [x] 歌词附近不出现独立细小光点星云或局部粒子点云。
- [x] 默认主题和 `animal-island` 主题下状态、空态、错误态和回退歌词仍可读。
- [x] 不新增歌词文本、歌曲路径、播放 URL、Cookie、token、音频数据或本机运行历史持久化。

## 完成记录

- [x] 已实现第一阶段：`MusicWindow.vue` 生成星河漫游专用运行态歌词状态并传给 `MusicWebglStarfield.vue`；WebGL 组件新增主歌词、上一句、下一句、柔光和反射 Mesh，使用 CanvasTexture 绘制同步进度高亮歌词；WebGL 歌词启用时 `MusicWindow.vue` 不再渲染 DOM 歌词 section。
- [x] 已完成空间感修正：歌词组基准 Z 深度从靠近相机的前景层推回星河主体层；新增仅包含大面积柔雾和光带的 WebGL 前景雾面，让歌词前方有轻微星云空气遮罩，同时避免回到细小光点点云效果。
- [x] 已完成播放起始消失问题重设：星河 WebGL 歌词不再把接管条件绑定到 `ready + 当前句非空`，而是由 WebGL 统一绘制歌词、加载、空态和错误；文字平面关闭深度写入和深度测试，放在柔雾与反射之后绘制，避免播放开始或歌词加载中出现 DOM 已取消但 WebGL 文本不可见的空场。
- [x] 已完成朝向与中心修正：歌词组从会自转的星河粒子 `sceneGroup` 移到同一个 Three.js 根 `scene`，位置固定在舞台中心锚点；歌词不再每帧复制相机四元数，只保留固定世界朝向和用户倾角，避免文字翻到背面、镜像显示或随相机/星河旋转偏出中心。
- [x] 已完成星河运动解耦：星河预设下 `sceneGroup` 不再自动自转，也取消默认相机 idle 绕转、鼓点相机 roll 和松手后的舞台惯性；歌词层不再复制 `camera.quaternion`，只保留固定世界朝向和用户倾角参数，主歌词材质改为正面渲染以避免背面镜像；星尘、星云团、流星轨迹和闪烁继续由粒子 shader 的时间和音乐参数驱动，避免歌词参照空间被舞台旋转牵着走。
- [x] 已完成主歌词刷新修正：`MusicWindow.vue` 传给 WebGL 的歌词状态补充当前句、上一句和下一句的运行态歌词行 key；`MusicWebglStarfield.vue` 把行 key 纳入 CanvasTexture 缓存签名，真实歌词行变化时即时重绘纹理，不增加 DOM 层、不增加切换动画、不保存歌词文本。
- [x] 已完成主歌词时间同步修正：播放器 `timeupdate` 事件在沉浸模式播放中也同步 `visualPlaybackTime`，WebGL 歌词不再只依赖沉浸 visual clock 推进，避免主歌词时间停在开头并一直显示歌名或第一句。
- [x] 已完成“间奏”占位修正：WebGL 主歌词不再把长间隔 `interlude` 状态翻译成“间奏”，而是继续使用真实歌词行；歌词解析同时过滤 LRC/YRC/纯文本里写成“间奏”“音乐间奏”或 `instrumental` 的占位行，避免非歌词文本进入主歌词。
- [x] 已完成歌名误入主歌词根因修正：歌词 ready 后 `lyricsAt()` 不再用 `track.title` 兜底当前句，WebGL 运行态也不再在 ready 状态下用歌名补空主句；当前句索引先基于过滤后的可显示歌词行计算，过滤纯音乐/间奏占位和完整文件名/艺人标题式身份行，避免出现“上下句正常但主句是歌名”。
- [x] 已完成主歌词显示模型重构：详见 `docs/music-main-lyric-display-redesign-requirements.md`；主歌词从可显示歌词行窗口生成，WebGL 当前平面按 `textMode` 明确区分歌词、加载、空态和错误态，不再混用歌曲标题兜底。
- [x] 已完成加载态占位修正：WebGL 加载态不再把“在线歌词读取中/本机歌词读取中”绘制成中心主歌词；歌词读取请求加入超时保护，超时后进入错误态并允许后续重试，避免中心主歌词长期卡在读取文案。
