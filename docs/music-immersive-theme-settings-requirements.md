# 沉浸模式独立主题设置需求计划

本文档记录音乐沉浸模式主题样式从桌宠界面主题中拆分，以及新增多套可切换沉浸主题的调整计划。该功能只保存界面主题枚举值，不保存用户歌曲路径、播放链接、Cookie、token、歌单内容、导入资源或本机运行历史。

## 背景

- 当前音乐窗口和沉浸模式共用桌宠界面主题。
- 用户希望沉浸模式的视觉风格可以独立设置，不受桌宠主界面主题切换影响。
- 沉浸模式已经有默认主题和 `animal-island` 主题样式，本次优先补齐设置入口和主题解析，不新增第三套主题。
- 后续用户要求参考 Mineradio 的沉浸式音乐体验，补充更多可切换主题样式。参考方向只取产品和视觉思路，不复制 GPL 代码、素材或播放链路。

## 目标

1. 在界面设置中新增“沉浸模式主题”选项。
2. 支持 `跟随桌宠主题`、`清爽默认`、`动物岛`、`电影暗场`、`星河电台`、`霓虹频谱`、`暖色舞台`、`深夜睡眠` 多种配置。
3. 普通音乐窗口继续使用桌宠界面主题。
4. 只有进入沉浸模式时，根节点、控制栏、歌词、播放列表、韵律面板和 Canvas 可视化使用沉浸主题。
5. 沉浸模式中的标题、作者、歌词、播放列表、按钮、标签、时间和提示文字需要跟随当前沉浸主题切换颜色、阴影、强调色和字重。
6. 默认值为 `跟随桌宠主题`，保证旧配置行为不变。
7. 沉浸模式韵律面板内提供即时切换入口，切换后保存到本机界面配置。

## 非目标

- 不新增独立视觉引擎，不引入 WebGL、Butterchurn 或大型第三方视觉依赖。
- 不改变音乐播放链路、歌单列表、在线平台登录或歌词读取逻辑。
- 不把音乐库、歌单、播放 URL、账号凭据或本机路径写入源码、文档示例或仓库。
- 不照搬 Mineradio 源码、素材、Logo、特定视觉命名或 GPL 实现。

## 方案

### 配置

- 在现有界面偏好配置中新增 `musicImmersiveTheme`。
- 可选值：
  - `follow`：跟随桌宠界面主题。
  - `light`：沉浸模式固定清爽默认。
  - `animal-island`：沉浸模式固定动物岛。
  - `cinema`：电影暗场，强调暗场、金色信号线和轻微胶片感。
  - `galaxy`：星河电台，强调星河粒子、青蓝光和空间感。
  - `neon`：霓虹频谱，强调高对比蓝紫霓虹、频谱和节拍脉冲。
  - `sunset`：暖色舞台，强调香槟金、橙红光和舞台灯。
  - `midnight`：深夜睡眠，强调低亮度、柔和蓝灰和少干扰。
- 后端保存时进行枚举归一化，未知值回退 `follow`。

### 设置页

- 在“界面主题”区域下方增加“沉浸模式主题”选择。
- 使用现有主题卡片视觉语言，补充多套紧凑选项。
- 说明文案只描述行为差异，不暴露内部配置路径。
- 沉浸模式韵律面板中增加轻量主题切换按钮，便于在播放中直接比较主题效果。

### 音乐窗口

- 音乐窗口保留 `drawerTheme` 用于普通播放器。
- 新增 `musicImmersiveThemePreference` 保存沉浸主题偏好。
- 新增 `resolvedImmersiveTheme`：
  - `follow` 时取 `drawerTheme`。
  - 其他值直接取对应主题。
- 进入沉浸模式时根节点和 `MusicVisualizerCanvas` 使用 `resolvedImmersiveTheme`。
- `MusicVisualizerCanvas` 增加对应调色板，但继续复用当前 Canvas 绘制逻辑，避免引入 WebGL 或大型第三方依赖。
- 主题 CSS 覆盖沉浸模式专用区域，不影响普通音乐窗口和桌宠界面。
- 文字样式统一从沉浸主题变量读取，避免背景切换后歌词或列表文字仍使用默认白色样式。

## 主题检查

1. 默认主题：确认沉浸模式固定 `light` 时保持深色清爽视觉，控制栏、列表、歌词和空状态可读。
2. `animal-island` 主题：确认沉浸模式固定 `animal-island` 时使用暖色 Canvas 和动物岛控件风格。
3. 新增主题：
   - `cinema`：控件和歌词在暗场下清晰，金色文字高亮不过曝。
   - `galaxy`：星河蓝绿背景和玻璃控件对比足够。
   - `neon`：蓝紫霓虹不遮挡歌词和列表，文字带主题发光但保持可读。
   - `sunset`：橙金暖色主题下按钮、滑块和错误提示可读。
   - `midnight`：低亮度下仍能识别当前歌词、播放按钮和列表高亮。
4. 组合检查：
   - 桌宠主题为 `light`，沉浸主题为 `animal-island`。
   - 桌宠主题为 `animal-island`，沉浸主题为 `light`。
   - 沉浸主题为 `follow` 时保持历史行为。
