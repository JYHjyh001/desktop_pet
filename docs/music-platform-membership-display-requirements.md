# 音乐平台账号会员信息显示需求

本文档记录音乐窗口网易云音乐和酷狗音乐账号凭据区域新增会员信息展示。本功能只展示账号会员摘要，不展示、不返回、不持久化平台 Cookie、token、设备标识、播放 URL、歌曲路径、歌词文本或音频数据。

## 背景

平台音乐播放失败可能与账号会员状态、地区、版权或设备授权有关。当前账号卡片只显示昵称、用户 ID 和本机保存时间，用户无法直观看到当前登录态是否检测到会员相关信息。

## 目标

- 在网易云和酷狗账号凭据卡片中显示会员摘要。
- 展示内容仅包含脱敏状态，例如会员类型、等级、到期时间、是否检测到会员播放凭据。
- 保持登录状态读取、二维码登录和退出清除流程兼容。
- 默认主题和 `animal-island` 主题下会员摘要可读。

## 非目标

- 不绕过会员、版权、地区、DRM 或付费限制。
- 不显示 `vip_token`、Cookie、设备 ID、签名参数或播放 URL。
- 不新增外部会员校验服务。
- 不把会员状态用于替代平台播放授权判断。

## 实现方案

1. 后端登录 profile 增加可选 `membership` 字段。
2. 网易云从账号状态响应中的常见会员字段提取摘要。
3. 酷狗从扫码登录响应和本机登录凭据中的 `vip_type`、`vip_token` 是否存在推断摘要。
4. 前端账号卡片在昵称和用户 ID 下方显示会员摘要。
5. 缺少会员信息时显示“未检测到会员信息”或“普通账号”，避免误导用户。

## 隐私边界

- 前端只接收会员摘要字段。
- 不返回 `vip_token`、Cookie、设备标识或原始平台响应。
- 文档只写边界和字段说明，不写用户账号、路径或真实凭据。

## 验收标准

- 网易云账号卡片可以显示会员摘要。
- 酷狗账号卡片可以显示会员摘要。
- 会员摘要不会包含 token、Cookie、设备 ID 或播放 URL。
- 退出登录后会员摘要随 profile 清空。
- `npm run build` 和 `npm run tauri:build` 通过。
