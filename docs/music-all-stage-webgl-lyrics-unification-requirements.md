# 全舞台 WebGL 歌词统一需求计划

本文档记录沉浸音乐模式中把所有舞台预设的歌词显示统一为星河漫游 WebGL 歌词方式的实现计划。本功能只使用当前运行态歌词文本、同步进度和视觉参数生成临时 CanvasTexture，不保存歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 背景

当前星河漫游使用 `MusicWebglStarfield.vue` 内的 WebGL 歌词平面，地面 DJ 等其他舞台仍会回落到 DOM 悬浮歌词。这样不同舞台的歌词层级、遮挡感和空间感不一致。用户希望所有舞台预设都采用星河漫游的歌词方式。

## 目标

1. WebGL 可用且存在当前歌曲时，所有舞台预设都使用同一套 WebGL 歌词平面显示当前句、上一句和下一句。
2. 星河漫游原有的 CanvasTexture 绘制、同步进度高亮、柔光和前景雾面继续复用，不为其他舞台引入新的 DOM 主歌词层。
3. DOM 歌词只作为 WebGL 未启用、WebGL 不可用或无当前歌曲时的回退。
4. 当前句状态仍即时替换，不增加歌词同步延迟；视觉上允许当前三行平面做短补间，让下一句移动放大到当前句位置，当前句移动缩小到上一句位置。
5. 默认主题与 `animal-island` 主题继续继承现有 WebGL 歌词配色和回退样式。
6. WebGL 歌词和 DOM 回退歌词都不显示倒影或地面反射效果。

## 非目标

1. 不修改歌词解析、在线歌词读取、逐字同步或播放时间同步链路。
2. 不复制第三方项目代码、资源、纹理或视觉参数。
3. 不把歌单卡片或主题卡片重做成 3D 对象。
4. 不保存任何歌词文本、歌曲路径、播放 URL、平台 Cookie、token、音频数据或本机运行历史。

## 实现步骤

1. 阅读 `docs/RELEASE_PRIVACY_CHECKLIST.md`，确认隐私边界。
2. 调整 `MusicWindow.vue` 中 WebGL 歌词状态的启用条件，从仅星河漫游改为所有 WebGL 舞台预设。
3. 调整 `MusicWebglStarfield.vue` 中 WebGL 歌词层的渲染条件，移除内部 `stagePreset === 'galaxy'` 限制。
4. 移除 WebGL 歌词反射平面和 DOM 回退主歌词倒影伪元素。
5. 给 WebGL 当前句切换增加仅视觉层的短补间，不改变歌词状态更新时间。
6. 保留 DOM 歌词回退逻辑，确保 WebGL 不可用或无当前歌曲时界面仍可读。
7. 运行构建、`git diff --check`、默认主题/`animal-island` 静态样式检查、隐私关键词扫描和 `.gitignore` 检查。

## 验收标准

- [x] DOM 歌词不会在 WebGL 歌词启用时叠加显示。
- [x] 当前句、上一句、下一句和错误/空态仍由现有歌词状态驱动。
- [x] 当前句切换时，下一句会移动放大到当前句位置，当前句会移动缩小到上一句位置；降低动态时禁用该补间。
- [x] WebGL 歌词和 DOM 回退歌词不再显示倒影。
- [x] 默认主题与 `animal-island` 主题无新增未适配入口。
