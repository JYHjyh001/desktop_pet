# 沉浸模式实时可视化样式需求计划

本文档记录沉浸模式实时频谱、线条和波纹样式扩展计划。该功能只保存界面样式枚举值，不保存用户歌曲路径、播放 URL、歌词内容、音频数据、音频指纹、平台 Cookie、token 或本机运行历史。

## 背景

- 当前沉浸模式已有实时频谱、光带和节拍脉冲，但频谱、线条和波纹绘制形态固定。
- 用户希望参考 Mineradio 的沉浸视觉方向，为实时频谱、线条和波纹增加多个可切换样式。
- 参考范围只包括沉浸氛围、粒子、舞台、节奏镜头等产品视觉思路，不复制 Mineradio 的 GPL 代码、素材或播放链路。

## 目标

1. 在沉浸模式韵律面板中增加“频谱”“线条”“波纹”样式切换入口。
2. 支持多种实时频谱样式：
   - `bars`：经典竖条，保留当前稳定频谱表现。
   - `mirror`：镜像棱柱，上下对称并带低频冲击感。
   - `orbit`：环形星盘，围绕中心绘制频谱刻度和脉冲轨道。
   - `particles`：粒子星河，用频段能量驱动星辰、光尘、柔光光晕、节拍闪烁和低频外扩。
   - `ribbon`：流光丝带，用连续曲线表达中高频流动。
   - `none`：隐藏实时频谱层，只保留其他可视化层。
3. 支持多种线条样式：
   - `wave`：柔波，保留当前连续波线。
   - `beam`：光束，多层横向光带随节拍拉伸。
   - `scan`：扫描，横向扫描线和细节线形成电子感。
   - `constellation`：星轨，点线连接形成星座式流动线条，并随节拍、低频和音量增强亮度、粗细和外扩。
   - `none`：隐藏线条层，只保留背景、频谱和波纹等其他层。
4. 支持多种波纹样式：
   - `rings`：圆环，保留当前扩散椭圆波纹。
   - `water`：水波，多层横向水面涟漪。
   - `heartbeat`：心跳，低频驱动的短促冲击波。
   - `halo`：光晕，中心径向柔光随能量呼吸。
   - `none`：隐藏波纹层，只保留背景、频谱和线条等其他层。
5. 三类样式都支持独立隐藏，用户可以按需要关闭实时频谱、线条或波纹中的任意一层。
6. 三类样式和沉浸主题独立，切换主题时可视化使用当前主题调色板。
7. 三类样式和视觉模式协作：视觉模式决定动态强弱，样式决定绘制形态。
8. 三类样式保存到本机运行时设置，重新打开音乐窗口后恢复。

## 非目标

- 不引入 Butterchurn 或大型第三方可视化引擎；WebGL 3D 主视觉继续使用本项目已有的 `MusicWebglStarfield` 轻量实现。
- 不改变当前播放链路、在线平台登录、歌词读取或歌单逻辑。
- 不把实时频谱数据、音频片段、播放 URL、歌曲列表或本机路径写入源码、文档示例或仓库。
- 不照搬 Mineradio 源码、素材、Logo、命名或 GPL 实现。

## 方案

### 状态

- 新增 `visualSpectrumStyle`、`visualLineStyle`、`visualRippleStyle` 本机设置字段。
- 默认值为 `bars`，确保旧用户行为不变。
- 线条默认值为 `wave`，波纹默认值为 `rings`，确保旧用户行为不变。
- 存储位置继续沿用音乐窗口现有运行时设置，不进入源码配置模板。

### 界面

- 在沉浸韵律面板中新增“频谱”“线条”“波纹”按钮网格。
- 按钮使用现有沉浸面板样式，默认主题、`animal-island` 主题和新增沉浸主题均继承已有按钮视觉。
- 面板顶部状态文案显示当前视觉模式、频谱、线条和波纹样式，方便确认切换结果。

### Canvas

- `MusicVisualizerCanvas` 增加 `spectrumStyle`、`lineStyle`、`rippleStyle` 属性。
- 背景、网格、线条、波纹继续复用主题调色板。
- WebGL 可用时作为回退背景和降级路径；WebGL 不可用或上下文丢失时继续承接频谱、线条和波纹绘制。
- 根据 `spectrumStyle` 分派不同绘制函数：
  - 经典竖条：稳定、低风险，适合作为默认回退。
  - 镜像棱柱：频谱从中轴上下展开，强调节拍冲击。
  - 环形星盘：频段围绕中心分布，适合沉浸舞台感。
  - 粒子星河：用固定伪随机点位和频段能量绘制星辰，节拍和低频触发粒子增亮、放大、柔光光晕、亮芯闪耀和放射线，避免每帧随机抖动。
  - 流光丝带：绘制多层连续曲线，适合低干扰和歌词场景。
- 根据 `lineStyle` 分派不同绘制函数：
  - 柔波：当前稳定波线。
  - 光束：多层水平光带，突出舞台灯效果。
  - 扫描：横向扫描线，突出电子频谱感。
  - 星轨：固定伪随机点连接，节点和连线随节拍、低频和音量增强，突出星河氛围。
- 根据 `rippleStyle` 分派不同绘制函数：
  - 圆环：当前稳定扩散环。
  - 水波：横向水面涟漪。
  - 心跳：低频短促脉冲。
  - 光晕：中心径向柔光呼吸。

### WebGL

- `MusicWebglStarfield` 在 WebGL 可用时承接 3D 频谱、线条、波纹和星轨。
- 主题调色板拆分为频谱色、线条色、波纹色和光晕色，避免所有样式共用同一脉冲色。
- 竖条、棱柱、星盘、星辰、丝带在 WebGL 空间中使用不同色彩通道和深度形态。
- 柔波、光束、扫描、星轨分别使用主题线条色和高亮色。
- 圆环、水波、心跳、光晕分别使用主题波纹色和光晕色。

## 主题检查

1. 默认主题：频谱、线条和波纹样式均可读，不遮挡歌词和控制栏。
2. `animal-island` 主题：按钮保持动物岛样式，可视化颜色柔和不过曝。
3. 新增沉浸主题：可视化使用主题调色板，不出现背景切换但线条或波纹仍是默认配色的问题。
4. 降低动态：粒子、环形、镜像、扫描和心跳样式减少旋转、闪烁和快速漂移。
