# 音乐迷你窗口贴边自动隐藏需求

状态：已实现。

## 目标

让音乐播放界面处于迷你状态时，用户把窗口拖到屏幕边缘附近后，窗口自动吸附并隐藏到对应屏幕边缘，只保留一小段可感知的边缘区域。鼠标移入迷你播放器时自动滑回可见区域，方便继续控制播放。

## 范围

- 仅作用于音乐播放器迷你状态。
- 普通音乐窗口、列表模式和沉浸模式不启用自动隐藏。
- 不保存窗口贴边位置、屏幕信息或用户本机路径。
- 使用 Tauri 窗口前端 API 读取当前窗口位置、尺寸和当前显示器工作区。

## 行为规则

- 迷你窗口拖动结束后，如果窗口距离当前显示器工作区左、右、上、下边缘足够近，则吸附到最近边。
- 吸附后先把迷你窗口完整贴齐屏幕工作区边缘，再在鼠标未停留时移动到屏幕外侧，只保留可触发的可见边。
- 吸附、展开和隐藏都使用短动画过渡，避免窗口瞬移造成生硬感。
- 每次拖拽开始时清理上一轮吸附状态和延迟检查，避免窗口回弹到上一次吸附位置。
- 鼠标进入迷你播放器时，窗口从隐藏边缘滑回屏幕内。
- 鼠标离开后，如果仍处于迷你状态且没有切换回完整窗口，则再次隐藏到原贴边。
- 切换到完整窗口或沉浸模式时清除贴边隐藏状态，避免普通窗口停留在屏幕外。

## 主题要求

- 默认主题新增贴边隐藏提示条视觉。
- `animal-island` 主题继承同一交互，并提供对应纸感/薄荷色样式。

## 验证

- `npm run build` 通过。
- 迷你模式下贴近四个屏幕边缘拖动后能自动隐藏。
- 鼠标移入迷你播放器能自动展开，移出后能重新隐藏。
- 默认主题和 `animal-island` 主题下提示条可见且不遮挡控制。
