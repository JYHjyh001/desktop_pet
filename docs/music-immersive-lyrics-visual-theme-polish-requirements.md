# 沉浸歌词位置与视觉主题细化需求计划

本文档记录沉浸模式歌词位置、歌词前景层级，以及频谱、线条、波纹在不同沉浸主题下的细化调整。本次功能只处理界面布局、运行态音乐能量摘要和主题枚举，不保存用户歌曲路径、播放 URL、歌词内容、平台 Cookie、token、音频数据或本机运行历史。

## 背景

- 沉浸模式已经接入 WebGL 3D 主视觉，但歌词仍偏向大块居中显示，容易和空状态、面板、控制栏抢视觉焦点。
- 参考 Mineradio 的视觉方向，歌词应像舞台前景层一样独立于背景可视化，具备明确位置、遮罩边界、唱词进度高亮和节拍光晕。
- 频谱、线条、波纹已可切换，但部分样式在 WebGL 3D 场景中仍共用同一组颜色，主题差异不够明显。

## 目标

1. 调整沉浸歌词显示位置：
   - 桌面端放到画面中下偏左的前景歌词带，避开顶部标题、左右面板和底部控制栏。
   - 窗口较窄或移动尺寸时居中显示，并上移避开底部控制。
   - 没有正在播放歌曲时降低歌词提示占用，避免和空状态卡片重叠。
2. 强化歌词视觉层级：
   - 当前行使用横向羽化遮罩。
   - 当前行使用唱词进度渐变，突出已唱部分。
   - 歌词光晕跟随主题色和节拍强度。
   - 前后句保持弱化、后移和轻微虚化，减少重叠。
3. 完善 WebGL 频谱、线条、波纹主题样式：
   - 不同主题提供独立的线条色、波纹色和光晕色。
   - 不同频谱样式在 WebGL 中有更明显的色彩差异。
   - 线条和波纹不再全部共用同一脉冲色。
4. 默认主题、`animal-island` 主题和新增沉浸主题都要保持可读、不过曝、不遮挡控件。

## 非目标

- 不改变播放链路、在线音乐登录、歌单、歌词解析或音频代理逻辑。
- 不复制 Mineradio 源码、shader、素材或 GPL 实现。
- 不新增用户歌词位置持久化配置；本次先提供稳定默认布局。
- 不把歌曲路径、歌词文本、播放 URL、Cookie、token 或本机资源写入源码或文档示例。

## 方案

### 歌词位置

- 新增沉浸歌词布局 CSS 变量：
  - `--immersive-lyrics-top`
  - `--immersive-lyrics-bottom`
  - `--immersive-lyrics-max-width`
  - `--immersive-lyrics-edge`
- 桌面端使用左对齐前景歌词带。
- 移动端使用居中布局，并降低主行字号上限。
- 空状态和错误状态收敛为较小提示。

### 歌词视觉

- 歌词容器加入横向 mask，避免文字贴边。
- 当前歌词文字使用渐变高亮和进度羽化。
- 当前行下划进度条弱化，避免和主文字进度重复抢眼。
- 前后句使用 3D 深度和透明度弱化。
- `animal-island` 使用暖色纸感光晕，其他沉浸主题使用各自强调色光晕。

### WebGL 视觉主题

- `MusicWebglStarfield` 的主题调色板增加：
  - `line`
  - `ripple`
  - `halo`
- Shader 中频谱、线条、波纹分别使用不同主题色。
- 星轨、扫描、水波、光晕等样式按主题增强对比，但继续受强度和降低动态控制约束。

## 验收标准

- [x] 歌词位置避开顶部标题、左右面板和底部控制栏。
- [x] 空状态下歌词提示不再压在主要空状态卡片背后形成大字干扰。
- [x] 当前歌词具备主题化渐变高亮、横向羽化和节拍光晕。
- [x] 默认主题、`animal-island` 主题和新增沉浸主题下歌词可读。
- [x] WebGL 频谱、线条、波纹使用主题化线条色、波纹色和光晕色。
- [x] WebGL 不可用时 Canvas 回退仍保持原主题调色。
- [x] `npm run build` 通过。
- [x] 隐私检查清单通过。
