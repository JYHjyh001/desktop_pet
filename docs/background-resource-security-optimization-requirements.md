## 目标与边界

降低未使用窗口的初始化及后台驻留；为 AI 传输、图片、历史与密钥建立明确边界，沿职责渐进拆分。保留后台音乐、托盘、通知、快捷键、双主题和已有翻译 API 语义。

仅修改本任务必要源码、依赖与记录，允许本地测试和隔离完整 UI 构建。不提交、推送、发布或安装，不自动请求真实服务，不覆盖真实配置或删除用户历史/资源。任务前 19 个跟踪修改、12 个未跟踪文件均保留，以被忽略的本地源码对照区分本任务差异。

最新授权：用户明确要求“直接在原程序上修改，删除候选程序”。完成必要验证后使用标准 `npm run tauri:build` 更新、重启原 Release；停止并删除经实际路径核实的本任务隔离候选程序与构建目录。该授权不包含提交、推送、发布、安装或覆盖用户配置。

## 阶段与接口

### A：受控基线与窗口生命周期

- 使用相同隔离应用标识、默认合成数据、构建方式和机器对比；仅统计目标进程及直接 WebView2 子树，排除启动的其他应用。记录进程数、工作集、私有提交、整机 CPU、句柄，分别观察 1/10/30 分钟及开关窗口 20 次。未完成采样不得填实测结论。
- 启动只创建 pet；其他窗口沿原 tauri 配置按需创建，统一去重入口。页面注册完成后进行 readiness 握手；首次气泡/翻译预填通过后端保留状态拉取，避免首次事件丢失。
- 首轮保留有未保存草稿或音频宿主的窗口；不能直接销毁音乐窗口。无状态菜单/气泡可在后续安全回收；隐藏窗口应停无关动画和轮询。页面卸载需取消迟到监听和异步回调。
- 默认和 animal-island 继承原 DOM/样式；首次打开、重复打开、托盘、划选预填和气泡必须回归。

### B：传输、媒体、历史资源

- 提取复用 Rust AI transport，沿用 provider 请求体及鉴权。总超时 60 秒、连接超时 10 秒、并发最多 4 个，超额直接返回忙碌；响应上限 12 MiB，在完整缓冲/JSON 解析前执行，图文消息仍为 8 MiB。禁止自动重定向，杜绝敏感头跨来源及 HTTPS 降级；保留系统代理和 localhost 服务，TLS 不关闭校验。错误仅返回固定类别/状态码，不回显服务响应或 URL。
- 取消必须有调用方明确作用域；传输任务超时/取消/错误均释放槽位，不能以丢弃前端结果代替停止接收。
- 图片：单图编码/下载上限 4 MiB，边长不超过 4096、像素不超过 1600 万，解码内存上限 64 MiB。远程图片不带 AI 凭据，禁止不受限内网代理、重定向和 DNS 重绑定；使用受控拉取/本机引用时必须复核来源与总配额。
- 新附件本机配额暂定 128 MiB，达到上限拒绝新附件，不自动删除旧资源；旧 Markdown/Base64 兼容，不做破坏性批量迁移。分页默认 20 条、最多 50 条，单页序列化预算 8 MiB；超大旧单条必须可按需查看，不能静默丢失游标。
- 素材文件先检查字节/头部尺寸，再按解码限额读取；图集仅允许既有标准尺寸。

### C：本机密钥保护

- Windows 使用当前用户 DPAPI，仅加密 config.json 中全局 AI、连接 profiles、独立翻译及其他实际密钥字段；公开 DTO 与 Keep/Replace/Clear 语义保留。
- 明文旧配置兼容只读；用户明确保存设置时升级，位置/窗口偏好等自动保存不得顺带迁移真实旧密钥。解密、加密或原子替换失败须返回固定错误并保留原文件，不回退明文、不清空密钥、不生成明文备份。
- 换机器/换 Windows 用户及降级不保证解密；使用合成数据验证，不自动改用户配置。非 Windows 保护策略须明确，不能假装已加密。

### D：职责拆分

优先窗口生命周期、AI transport、媒体边界与历史分页访问，再沿完整职责提取音乐/Drawer/Kugou 模块。每步有回归证据，不做全仓格式化或依赖主版本升级。拆文件不作为内存收益证据。

### 已实现的源码边界

- PET-OPT-001-A：`window_lifecycle.rs` 统一按需创建、去重及前端 readiness 握手，启动只创建 pet，其余 7 个窗口首次打开时创建；创建入口转到阻塞工作线程，避免 Windows 同步 UI 命令死锁。打开后的窗口隐藏保留，保护草稿与音频，不声称已做到所有窗口自动回收。`useScopedListeners.ts` 清理卸载后才完成注册的监听；音乐未创建时退出不再等待 flush。
- PET-OPT-001-B：`ai_transport.rs` 使用复用 Rust HTTP 客户端，保留 provider 请求体/鉴权，连接 10 秒、总计 60 秒、并发 4、请求/响应 12 MiB，关闭自动重定向；按窗口作用域取消接收并释放槽位。使用系统证书根和系统代理能力，测试客户端禁止使用本机代理；PAC 与真实服务兼容仍待验。
- PET-OPT-001-B：`chat_media.rs` 对下载、编码、尺寸、像素、解码分配与动画总量校验；下载和解码各最多并发 2。静态 WebP 也执行实际解码。远程 HTTPS 图片禁止携带凭据、使用代理、跟随重定向或访问本机/内网/保留地址，解析后固定 DNS 地址。新 Base64 图片保存为本机附件，128 MiB 配额、内容去重、冲突拒绝覆盖；不自动删除旧历史或附件。
- PET-OPT-001-B：`message_history.rs` 默认 20/最多 50 条游标分页，单页 JSON 预算 8 MiB，大旧记录保留游标并可显式单条读取；前端翻页替换当前页。单条原文限制 8 MiB，JSON 转义后可能更大。新旧图片源都从模型上下文剥离，最近上下文/压缩批次文本预算各 1 MiB；压缩批次最多 40 条。删除原自动裁剪 200 条历史的行为。
- PET-OPT-001-B：聊天图片进入视口后经受限 IPC 加载，离开视口/页面隐藏后丢弃解析地址，迟到结果失效；应用没有持久图片内存缓存，浏览器内部缓存和整个进程内存不承诺固定上限。导入/导出上限 32 MiB，导出计入 JSON 转义、包装及长期记忆，序列化中执行上限，原子替换目标；附件迁移保留旧目录以便回退。
- PET-OPT-001-C：`config_secrets.rs` 在磁盘序列化层使用当前 Windows 用户 DPAPI，覆盖全局 AI、连接档案、翻译和 Bridge Token；前端 DTO 不变。明确保存设置时升级旧明文，自动位置保存不升级旧明文；受保护字段不回退明文。损坏配置/保护失败保留原文件，不创建明文配置备份。非 Windows 拒绝新增密钥保护写入；不承诺跨用户/机器或旧版降级兼容。
- PET-OPT-001-D：已按完整职责提取窗口、传输、媒体、历史、密钥和音乐合并持久化队列；本轮没有为缩短文件而大范围改写 Drawer/Kugou。其余超大文件继续拆分保留工程维护待办。
